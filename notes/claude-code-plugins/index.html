    官方市集之外

    官方那 286 個只是被 Anthropic 收編的部分。社群自建的市集到 2026 年中已經有 9000 多個第三方項目，其中幾個值得單獨加進來。加市集跟裝外掛是兩個動作，順序不能反。

    superpowers-marketplace

    obra 維護的精選市集，superpowers 系列的老家，另外還有 instincts、memory、research-first 幾個延伸。

    claude plugin marketplace add obra/superpowers-marketplace

    claude-mem

    跨 session 的持久記憶：自動壓縮你做過的事，下次開新視窗時把相關脈絡塞回來。裝完要重開 Claude Code。

    claude plugin marketplace add thedotmack/claude-mem
claude plugin install claude-mem@thedotmack

    superpowers-zh

    superpowers 的中文增強版，另外加了 6 個中國原創 skill。你如果想看中文 skill 怎麼寫，這是現成範本。

    claude plugin marketplace add jnMetaCode/superpowers-zh
    裝之前先知道三件事。 一、掛 MCP server 的外掛（Notion、Slack、Stripe 這類）第一次用要走 OAuth 授權，而授權流程只能在互動式的終端機 session 裡跑，非互動視窗會卡住。 二、外掛不是裝越多越好——每個掛上的 skill 描述都會佔掉開場的 context，二三十個之後你會感覺到變鈍，建議一次裝一批、用一週、砍掉沒開過的。 三、LSP 系列（pyright、csharp 那些）只在你真的在寫該語言時才有價值，平常掛著純粹是負擔。
