03

三大風險 × 緩解策略

Risk Matrix
⚠ 高風險 · 發生機率 70%+

封號 / 資產歸零

MMORPG 反掛機制成熟：同 IP 多開偵測、行為模式分析、裝置指紋比對。雷電模擬器本身就在多數大廠黑名單。你論文研究 UAV 的反偵測方法，這裡其實是同類問題。

多帳號分 IP（4G 分享器輪替）+ 隨機延遲 + 每日上線時間差異化 + 分散儲值風險
⚠ 高風險 · 發生機率 30-50%

8591 交易詐騙

常見手法：買家假匯款截圖、第三方支付盜刷、面交強搶帳號、事後爭議退款。賣家在糾紛中幾乎總是輸的一方，因為虛擬商品無法「退回」。

只接銀行轉帳 + 確認入帳 15 分鐘才交貨 + 保留全程對話 + 不走超商代收 + 單筆金額上限 NT$5,000
△ 中風險 · 必然發生

電費 + 硬體吃光利潤

每月固定成本 ≈ NT$1,260 (電) + NT$500 (硬體折舊) = NT$1,760 保本線。如果單帳號月產值低於 NT$300，6 開也只能打平。

第一個月只跑 3 開驗證單位產值 → 用 ROI 決定要不要擴到 10 開。夜間離峰電價 + 白天伺服器託管（爸媽家）
△ 法律灰色

法律地帶分析

台灣目前：腳本掛機本身不違法（違反遊戲商服務條款，民事），但：
① 販售外掛程式 → 刑法妨害電腦使用罪
② 盜用他人帳號/寶物 → 刑事
③ 未申報所得超過 NT$84,501/月 → 逃漏稅

不販售腳本本體、只賣正常獲取的遊戲幣/寶物、年收入超過免稅額老實報「網路拍賣所得」

WEEK 03-04 · 腳本期

Checkpoint：14 天未收警告 → 進入矩陣期
WEEK 05-08 · 矩陣期

Checkpoint：月淨利 ≥ NT$3,000 才值得繼續
WEEK 09-12 · 最佳化期

8591 變現優化 + 決定是否放大

動態定價腳本、買家 VIP 分級、自動 FAQ 回覆。累計 90 天數據做成報表，用真實 ROI 決定下一季戰略（收手/持平/追加投資）。

def price_scout(game_id):
