Claude Code Help 雙語速查

claude [options] [command] [prompt]

預設啟動互動式對話 ─ 加 -p 印完就走

日常必備 Session 管理 模型與 Prompt 權限與安全 工具與外掛 進階開發 子命令

日常必備

-c, --continue

Continue the most recent conversation in the current directory

接續這個資料夾裡最近一次對話

-r, --resume [value]

Resume a conversation by session ID, or open interactive picker with optional search term

用 session ID 恢復對話；不加 ID 會跳出選單讓你挑

-p, --print

Print response and exit (useful for pipes)

印完回應就結束，適合接 shell 管線，例如 echo "翻譯這段" | claude -p

-n, --name <name>

Set a display name for this session (shown in prompt box, /resume picker, terminal title)

幫對話取名字，之後在 /resume 選單和標題列都看得到

--model <model>

Model for the current session. Provide an alias (fable, opus, sonnet) or full name.

指定這次對話用的模型，打別名（fable / opus / sonnet）或完整名都行

--effort <level>

Effort level for the current session (low, medium, high, xhigh, max)

思考力度：low 快但淺、max 慢但深

-v, --version

Output the version number

顯示版本號

-h, --help

Display help for command

顯示說明（就是這頁的內容）

Session 管理

--bg, --background

Start the session in the background and return immediately

背景跑，終端機馬上還你。之後用 claude attach 接回來

--cloud [description|session_id|url]

Create a cloud session or attach to an existing one by session ID or claude.ai/code URL

建立雲端 session，或用 ID / URL 接回既有的

-w, --worktree [name]

Create a new git worktree for this session (optionally specify a name)

開一個獨立的 git worktree，不會動到你的主分支

--tmux

Create a tmux session for the worktree (requires --worktree)

搭配 worktree 開 tmux 分割畫面，有 iTerm2 會用原生分頁

--desktop

Open in the Claude Desktop app instead of the terminal

用 Claude 桌面版開，不在終端機裡

--fork-session

When resuming, create a new session ID instead of reusing the original

恢復對話時產生新 ID，不覆蓋原本的 session

--session-id <uuid>

Use a specific session ID for the conversation (must be a valid UUID)

指定一個 UUID 當 session ID

--from-pr [value]

Resume a session linked to a PR by PR number/URL, or open interactive picker

恢復跟某個 PR 綁定的 session

--teleport [session]

Resume a teleport session, optionally specify session ID

恢復 teleport session

--no-session-persistence

Disable session persistence — sessions will not be saved to disk (only with --print)

不存 session，結束就消失（搭配 --print 用）

模型與 Prompt

--system-prompt <prompt>

System prompt to use for the session

自訂系統提示詞，會取代預設的

--append-system-prompt <prompt>

Append a system prompt to the default system prompt

在預設系統提示詞後面追加內容（不會取代）

--system-prompt-snapshot <on|off>

Record the system prompt once and reuse it verbatim on every request and resume

on（預設）：第一次就鎖定提示詞，之後 resume 都用同一份。off：每次都重新產生，適合調 prompt 時

--autocompact <auto|tokens>

Auto-compact window size (auto, or 100k–1M tokens)

自動壓縮對話，避免爆 context。auto 自動判斷，或填 token 數

--fallback-model <model>

Automatic fallback model(s) when default is overloaded. Comma-separated list.

主模型忙碌時自動切的備用模型，逗號分隔多個

--json-schema <schema>

JSON Schema for structured output validation

指定 JSON Schema，讓 Claude 的輸出符合特定結構

--max-budget-usd <amount>

Maximum dollar amount to spend on API calls (only with --print)

設花費上限（美元），超過就停

--prompt-suggestions

Enable prompt suggestions — emits predicted next user prompt after each turn

每輪結束後預測你下一步想問什麼

權限與安全

--permission-mode <mode>

Permission mode: acceptEdits, auto, bypassPermissions, manual, dontAsk, plan

權限模式。manual＝每次都問、auto＝自動判斷、dontAsk＝全不問

--permission-prompts <target>

Who answers permission prompts with --print: "host" or "none"

用 --print 時誰回答權限：host 交給程式、none 全部拒絕

--dangerously-skip-permissions

Bypass all permission checks. Recommended only for sandboxes with no internet.

跳過所有權限檢查 ⚠️ 只適合沒有網路的沙箱環境

--allow-dangerously-skip-permissions

Enable bypassing as an option, without it being enabled by default

允許「跳過權限」這個選項出現，但不預設開啟

--restricted

Restricted mode: removes Bash/PowerShell/REPL, confines file tools to working dirs

限制模式：拿掉 Bash 等執行工具，檔案操作只能在工作目錄裡

--safe-mode

Start with all customizations disabled — useful for troubleshooting

安全模式：關掉所有自訂（CLAUDE.md、hook、plugin、MCP 等），排錯專用

工具與外掛

--allowedTools <tools...>

Comma or space-separated list of tool names to allow (e.g. "Bash(git *) Edit")

只允許這些工具（白名單）

--disallowedTools <tools...>

Comma or space-separated list of tool names to deny

禁止這些工具（黑名單）

--tools <tools...>

Specify available tools. "" = none, "default" = all, or names like "Bash,Edit,Read"

指定可用工具清單。空字串全關、default 全開、或列名字

--mcp-config <configs...>

Load MCP servers from JSON files or strings

從 JSON 檔載入 MCP 伺服器設定

--strict-mcp-config

Only use MCP servers from --mcp-config, ignoring all other configurations

只用你指定的 MCP，忽略其他來源的

--chrome / --no-chrome

Enable / Disable Claude in Chrome integration

開啟 / 關閉 Chrome 瀏覽器整合

--ide

Automatically connect to IDE on startup if exactly one valid IDE is available

啟動時自動連上 IDE（VS Code / JetBrains）

--plugin-dir <path>

Load a plugin from a directory or .zip for this session only

載入本地外掛（資料夾或 .zip），只限這次 session

--plugin-url <url>

Fetch a plugin .zip from a URL for this session only

從網址下載外掛，只限這次 session

--disable-slash-commands

Disable all skills

關閉所有 slash command（skill）

進階 / 開發用

--add-dir <directories...>

Additional directories to allow tool access to

額外允許工具存取的資料夾（預設只有當前目錄）

--agent <agent>

Agent for the current session. Overrides the 'agent' setting.

指定這次 session 使用的 agent

--agents <json-or-file>

JSON object defining custom agents, or with --print a path to a file

用 JSON 定義自訂 agent（搭配 --print 可指定檔案路徑）

--bare

Minimal mode: skip hooks, LSP, plugins, auto-memory, CLAUDE.md auto-discovery

極簡模式：跳過 hook、LSP、外掛、自動記憶、CLAUDE.md 掃描

--betas <betas...>

Beta headers to include in API requests (API key users only)

API 請求加上 beta header，僅 API key 使用者

--brief

Enable SendUserMessage tool for agent-to-user communication

開啟 agent 主動傳訊給使用者的功能

-d, --debug [filter]

Enable debug mode with optional category filtering (e.g. "api,hooks")

開 debug 模式，可用逗號指定過濾類別

--debug-file <path>

Write debug logs to a specific file path

debug log 寫到指定檔案

--environment <id>

Create a new cloud session on the given self-hosted environment (ccpool_...)

在自架環境上跑雲端 session

--exclude-dynamic-system-prompt-sections

Move per-machine sections from system prompt into first user message

把機器相關資訊從系統提示詞移到使用者訊息，提高 cache 命中率

--file <specs...>

File resources to download at startup. Format: file_id:relative_path

啟動時下載的檔案資源，格式：file_id:路徑

--forward-subagent-text

Forward subagent text and thinking blocks (only with --print and stream-json)

轉發子 agent 的文字和思考過程

--include-hook-events

Include all hook lifecycle events in the output stream

在輸出串流中包含 hook 事件

--include-partial-messages

Include partial message chunks as they arrive

訊息片段一到就輸出，不等完整

--input-format <format>

Input format: "text" (default) or "stream-json"

輸入格式，預設純文字

--output-format <format>

Output format: "text", "json", or "stream-json"

輸出格式：純文字 / 單次 JSON / 串流 JSON

--remote-control [name]

Start an interactive session with Remote Control enabled

開啟遠端控制模式

--setting-sources <sources>

Comma-separated list of setting sources to load (user, project, local)

指定要讀哪些設定來源

--settings <file-or-json>

Path to a settings JSON file or a JSON string

載入額外設定檔

--verbose

Override verbose mode setting from config

開啟詳細輸出

--ax-screen-reader

Render screen-reader friendly output

螢幕閱讀器友善模式，去掉裝飾邊框和動畫

--replay-user-messages

Re-emit user messages from stdin back on stdout

把 stdin 的使用者訊息回送到 stdout

子命令 Commands

claude agents [options]

Manage background agents

管理背景 agent（列出、查看狀態）

claude attach <id|name>

Open a background session in this terminal

把背景 session 拉到當前終端機操作

claude auth

Manage authentication

管理登入驗證

claude auto-mode

Inspect or reset auto mode classifier configuration

查看或重設 auto mode 的分類設定

claude doctor

Check the health of your Claude Code installation

檢查 Claude Code 安裝是否正常，排錯用

claude gateway [options]

Run the enterprise auth/telemetry gateway

跑企業用的驗證 / 遙測閘道

claude import [source]

Import config from another AI coding agent into Claude Code

從其他 AI 程式工具（如 Cursor）匯入設定

claude install [target]

Install Claude Code native build (stable, latest, or specific version)

安裝原生版本

claude logs <id|name>

Print a background session's recent terminal output

印出背景 session 最近的終端機輸出

claude mcp

Configure and manage MCP servers

設定與管理 MCP 伺服器

claude plugin

Manage Claude Code plugins

管理外掛

claude purge [path]

Delete all Claude Code state for a project (transcripts, tasks, file history)

清除某專案的所有 Claude Code 狀態

claude respawn [id]

Restart a background session on the current Claude Code version

用當前版本重啟背景 session

claude rm <id>

Delete a background session, and its worktree when safe

刪除背景 session，有 worktree 也一起清

claude setup-token

Set up a long-lived authentication token (requires Claude subscription)

設定長效驗證 token，需有 Claude 訂閱

claude stop <id>

Stop a background session (conversation is kept)

停止背景 session，對話保留，之後可以 attach 回來

claude ultrareview [target]

Run a cloud-hosted multi-agent code review

跑雲端多 agent 程式碼審查

claude update

Check for updates and install if available

檢查並安裝更新
