ROS 2 白話入門 · 2026-10-20

ROS 2 是不是機器人語言？

不是。

ROS 2 不是程式語言；全名雖然叫 Robot Operating System，它也不是 Windows、macOS 那種作業系統。官方文件說它是 middleware（中介軟體）：夾在作業系統和你寫的程式中間，讓機器人裡的各支程式互相傳資料，另外附一整套工具。真正寫邏輯的，還是 Python 或 C++。

01先分三層看

很多人卡在「ROS 2 到底是哪一種東西」。把機器人的軟體想成一間公司，就分得出來：

表 1三層各管什麼
這一層比喻負責什麼
作業系統Linux（主場是 Ubuntu）辦公大樓管硬體、檔案、網路，讓程式有地方跑
程式語言Python、C++員工的腦袋每支程式怎麼判斷、怎麼做事
ROS 2中介軟體 middleware收發室＋群組＋公文格式程式之間怎麼傳話、資料長怎樣、怎麼找到彼此

所以 ROS 2 要裝在作業系統上。在 Mac 上跑 ROS 2，通常要先開一台 Linux 虛擬機或容器，等於先蓋一棟 Linux 大樓給它住。

也因為大家用同一間收發室、填同一種表單，Python 寫的程式和 C++ 寫的程式可以直接互傳資料。

02ROS 2 裡面的 5 個基本元件

官方文件把「哪些程式、透過哪些頻道連在一起」這整張網路叫做 ROS graph。這張網路由下面 5 種東西組成：

表 25 個基本元件
名詞白話比喻
node節點各管一件事的小程式例：深度感測程式、監督程式一位員工
topic話題持續廣播的資料頻道用在：感測器數值、相機畫面這種一直來的資料LINE 群組：發的人不知道誰在看，看的人也不知道是誰發的
message訊息頻道裡資料的固定格式例：Float32＝一個小數公文表單
service服務一問一答用在：偶爾查一次、要馬上拿到答案打電話問「電量剩多少？」
action動作要花時間的任務，途中回報進度、可以取消例：「下潛到 2 公尺」叫外送：下單 →「還有 5 分鐘」→ 送達

03程式長什麼樣？

拿水下機器人當例子：深度感測程式把深度發布到 depth 這個頻道，監督程式訂閱它，深度不對就喊停。兩支程式裡跟 ROS 2 有關的，各只有一兩行：

表 3訂閱和發布各是哪一行
角色關鍵那一行（Python）白話
監督程式訂閱者 subscriber self.create_subscription(Float32, 'depth', self.on_depth, 10) 加入 depth 群組，收到新訊息就交給 on_depth 處理
深度感測程式發布者 publisher self.pub = self.create_publisher(Float32, 'depth', 10) self.pub.publish(msg) 在 depth 群組發一張「一個小數」格式的表單
  • 這兩支都是 Python 程式。create_subscription、create_publisher 是 ROS 2 給 Python 用的函式庫 rclpy 提供的功能；C++ 版叫 rclcpp。
  • 兩邊只靠頻道名稱 depth 和表單格式 Float32 對上，彼此不用知道對方是誰。
  • 最後那個 10 是排隊上限：來不及處理的時候，最多先留 10 則。

04切切看：誰在發布 depth？

左邊兩個發布者可以開關，右邊的監督程式只看得到數字。試試 0 個、1 個、2 個發布者時，各會發生什麼事。

/depthFloat32
node · 訂閱者
監督程式
— m
正常收到

    $ ros2 topic info /depth
Type: std_msgs/msg/Float32
Publisher count: 1
Subscription count: 1
    表 4發布者數量和結果
    發布者監督程式看到什麼代表什麼
    0 個一直等不到資料，ROS 2 也不報錯一個頻道本來就允許沒人發布。實機少了一支發布程式時，最容易卡在這裡
    1 個正常收到深度，不知道也不在乎是誰發的這就是匿名（anonymous）的好處：從模擬換到實機，監督程式不用改
    2 個兩個來源的數字交錯出現，分不出誰是誰模擬器和實機同時開著時要小心

    表 5常跟 ROS 2 一起出現的名詞
    名詞是什麼比喻

    06那什麼才叫「機器人語言」？

    比較貼切的是工業機械手臂廠牌自己的程式語言：

    表 6工業手臂廠牌的程式語言
    廠牌語言
    ABBRAPID
    KUKAKRL（KUKA Robot Language）
    FANUCKAREL、TP（教導盒程式）

    有人說 ROS 2 是「機器人界的共通語言」，意思是大家都靠它溝通，這是比喻，不是程式語言。想看懂 ROS 2 程式，順序是先會 Python（或 C++），再學表 2 那 5 個元件。

    07想動手按按看

    官方入門教學從 turtlesim 開始：視窗裡有一隻小烏龜，用鍵盤開著牠走。接著〈Understanding topics〉那篇會開 rqt_graph，把節點和頻道畫成一張圖；開或關一支程式，圖上的連線就跟著變，跟上面的小實驗是同一件事。

    表 7新手最常用的三個指令
    指令做什麼
    ros2 topic list列出現在所有頻道
    ros2 topic echo /depth即時看這個頻道收到的每一則訊息
    ros2 topic info /depth看這個頻道有幾個發布者、幾個訂閱者
