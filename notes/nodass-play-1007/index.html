NODASS 可以玩什麼？

國家海洋研究院「國家海洋資料庫及共享平台」(NODASS) 的開放 API，搭配我們的 AUV 計畫，能做出哪些有趣、又拿得出手的東西。

先講結論

  • 測站 API 不用登入就抓得到。官網寫要登入，但 10/7 實測時，測站清單和「近 2 天監測值」都直接回傳 JSON。
  • 茄萣附近有現成的浮標。最近的是安平港浮球式波流站（約 7 km），還有彌陀資料浮標（約 16 km），浪高、流速、水溫每小時一筆。
  • 最大的發現：10/6 這一天兩個浮標量到的流速最高 0.6 m/s。學生 AUV 的巡航速度通常在 0.3–0.5 m/s 上下（估計值），也就是說真的海流可能比我們的載具還快。這正是「為什麼先在水池比賽」最好的說明。
  • 要注意：瀏覽器直接呼叫會被擋，因為 API 沒回傳跨網域許可（CORS 標頭）。網頁要用資料，得先靠 GitHub Actions 定時抓下來存成檔案，網頁再去讀那份檔案。

8 個玩法

★ 越少越好做。「對應」是指這個玩法能用在哪裡：T-MARS 計畫書或加分作業、SAUVC、典典週報，或海委會的四大主題（保育、救難、海域偵巡、海纜維護）。

1. 「今天能下水嗎？」海況紅綠燈

★ 半天T-MARS 加分救難海域偵巡
一句話
抓最近浮標的浪高、流速、風速，自動亮 可以／小心／別下水。
怎麼玩
先自己定門檻，例如浪高 > 1 m 或流速 > 0.3 m/s 就亮紅燈，再寫一支 Python 小程式判斷。之後可以改成問 ORCA 學長：他們實際出海的門檻是多少？
用到
/obs/{StationID}/data

2. 把真實海流灌進模擬 AUV

★★ 1–2 天SAUVCauv-rest-kitT-MARS 計畫書
一句話
讓工具包裡的模擬 AUV 在「10/6 安平港外的真實海流」裡跑，看它會被推偏多遠。
怎麼玩
把流速、流向當成側向推力，加進 auv-rest-kit 的模擬器。分別跑 0.1 m/s 和 0.6 m/s 兩種情境，比較航向保持和心跳逾時的表現。出來的圖可以直接放進計畫書的「分階段測試計畫」。
用到
/obs/{StationID}/data（取 Current_Speed、Current_Direction）

3. 浮標的「心跳」監測

★ 半天營隊教的心跳機制海纜維護
一句話
營隊教 AUV 要有心跳，其實海上的浮標也一樣。我們可以幫全台的浮標做一張「誰還活著」的看板。
怎麼玩
每個測站都有 LatestDate 欄位，超過 N 小時沒更新就標成「失聯」。這跟營隊講的 REST 心跳是同一個概念，很適合拿來當教學範例：「看，國家級測站也會斷線。」
用到
/obs/stations/NAMR、CWA、IHMT、WRA

4. 自動更新的海況小看板

★★ 1 天展示亮點GitHub Pages
一句話
把玩法 1 和 3 做成網頁，每小時自動更新。
怎麼玩
瀏覽器不能直接呼叫 API，所以讓 GitHub Actions 每小時抓一次資料、存成 JSON，網頁再去讀那份檔案。好處是完全免費，也不用自己架主機。
用到
測站清單＋監測值；GitHub Actions 排程

5. AI 海況播報員

★ 半天典典週報AI 課程素材
一句話
把當天的海況 JSON 丟給 Claude，請它寫一段 3 句話的白話海況播報。
怎麼玩
剛好可以當成「給 AI 用的線上課程」的範例：真實的政府開放資料，經過 AI 整理，變成一般人看得懂的內容。可以放進電子報的固定專欄，例如「本週海況」。
用到
監測值＋Claude API

6. 水溫 → 聲速小計算機

★ 2 小時SAUVC 聲納任務教育
一句話
SAUVC 有聽聲音找目標（pinger）的任務，而聲音在水裡跑多快，會跟著水溫改變。
怎麼玩
用水溫算出水中聲速，大約 1,500 m/s 上下。比較海水 29.5 °C 和泳池水溫算出來差多少，再換算成定位誤差。順便提醒自己：比賽前要量泳池水溫，不能直接套海上的數字。
用到
Sea_Temperature（作為教學示範）

7. 「AUV 可以去哪裡」地圖

★★★ 2–3 天保育海域偵巡
一句話
把海域保護區、測站位置和海況疊在同一張地圖上，標出未來實海測試可以去、和要避開的地方。
怎麼玩
你電腦上有 QGIS，可以先在 QGIS 裡疊圖看看，再決定要不要做成網頁。比較適合當 SAUVC 之後的長期願景。
用到
/list/vector/OCA/NPMPA、測站清單

8. 衛星看海：葉綠素和海溫縮時

★★ 1 天典典週報海洋教育
一句話
把水試所的海溫衛星圖（2019 年至今）串成縮時動畫。
怎麼玩
挑一季的資料做成 GIF，視覺效果很好，適合放社群或電子報。注意：GOCI、Sentinel-3 那幾組圖資只到 2021–2022 年，比較適合拿來看歷史。
用到
/images/TFRIN_SST

建議順序

  1. 這週：玩法 1＋3。各花半天，用同一支抓資料的程式就能做完。這兩個最容易做出成果，也最能說明「我們懂心跳、懂安全」。
  2. T-MARS 前（10/31）：玩法 2。跟現成的 auv-rest-kit 接起來，產出的圖放進計畫書。
  3. 有空再做：玩法 4、5。做成看板和電子報專欄，屬於品牌的長期素材。
  4. SAUVC 之後：玩法 7、8。

API 速查

網址開頭都是 https://nodass.namr.gov.tw/noapi/namr/v1。日期參數用 date1、date2，格式是 YYYY-MM-DD。

要什麼路徑備註
測站清單/obs/stations/{NAMR|CWA|IHMT|WRA}回傳經緯度、LatestDate、資料網址
測站監測值/obs/{StationID}/data/?date1=…&date2=…只能抓最近 2 天，一小時一筆
海溫衛星圖/images/TFRIN_SST2019-11 至今
海域保護區/list/vector/OCA/NPMPA向量圖層
小陷阱：國海院有些測站的 ID 拼成 Vetor_（少一個 c），官方資料就是這樣，照抄就對了，別自己「修正」。

還要確認的事

  • 不用登入就能抓，是 10/7 實測的結果。國海院以後可能會改成要登入，正式用之前先跟國海院確認使用規範（電話 07-3382097）。
  • 公開使用時，記得註明資料來源是「國家海洋研究院 NODASS」，以及原始單位（水利署、運研所等）。
  • 近 2 天以外的歷史資料，要另外到平台申請下載。
