暖身：AI 期中考會用到的 5 招高中數學

建議 15 分鐘

想像你要打電動的魔王關，進關前總得先把裝備升級。這份 AI 期中考看起來很嚇人，Entropy、Naive Bayes、SVM、backprop 一字排開，但拆開來看，每一關背後都是你高中學過的數學換了件衣服：猜謎遊戲是 log，篩選垃圾信是條件機率，SVM 的「走道寬度」就是點到直線距離，神經網路學習則是沿著斜率下山。這一章先不碰考題，我們把 5 把鑰匙磨亮，之後每一題你都會有「啊，原來是這個」的感覺。

對數 Logarithm（\(\log_2\)）

「2 的幾次方會等於它」。\(\log_2 8 = 3\)，因為 \(2^3 = 8\)。白話就是：8 個一樣可能的答案，要問幾個是非題才猜得到。

高中數學：指數與對數函數

熵 Entropy

一堆資料「有多亂、多難猜」，單位是 bit，可以想成平均要問幾個是非題。決策樹靠它挑出最能減少混亂的問題，減少的量叫 Information Gain。

高中數學：對數＋機率（期望值）的延伸應用

條件機率 Conditional probability \(P(A\mid B)\)

先把範圍縮小到「B 已經發生」的那一群，再看 A 在裡面佔多少。像篩選器，先篩再數。

高中數學：條件機率

貝氏定理 Bayes' theorem

把條件機率「反過來」：已知垃圾信裡有多少含「免費」，反推含「免費」的信有多少是垃圾信。Naive Bayes 就建立在它上面。

高中數學：條件機率與貝氏定理

向量內積 Dot product

\(w\cdot x = w_1x_1 + w_2x_2\)，對應位置相乘再相加。AI 課本的 \(w\cdot x + b = 0\) 就是高中的直線 \(ax + by + c = 0\)。

高中數學：平面向量（內積、法向量）

點到直線距離 Point-to-line distance

\(d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}\)。SVM 的 geometric margin 就是這個距離，分母 \(\sqrt{a^2+b^2}\) 就是 \(\lVert w \rVert\)。

高中數學：直線方程式、點到直線距離

Sigmoid 函數

\(\sigma(z) = \frac{1}{1 + e^{-z}}\)，把任何數字壓進 0 到 1 之間的 S 形曲線，常用在神經元的輸出。\(e \approx 2.718\) 是數學裡常用的常數，當成一般的底數看就好。

高中數學：指數函數

導數 Derivative（斜率）

曲線在某一點的陡度：自變數動一點點，函數值跟著動幾倍。只看其中一個變數、其他當常數時叫偏微分，寫成 \(\frac{\partial L}{\partial w}\)。

高三數甲：多項式函數的微分

連鎖律 Chain rule

好幾層函數套在一起時，總倍率等於每一層的倍率相乘，像齒輪一個帶一個。Backprop（反向傳播）的核心就是它。

高三數甲微分的延伸（大一微積分正式教）

梯度下降 Gradient descent

看斜率決定往哪走，每次往下坡踏一步，慢慢把錯誤（loss）降到山谷最低點。神經網路就是這樣學習的。

暖身 1・log2 與「幾個是非題才猜得到」

這題要你搞懂 log2 就是「要問幾個是非題」，並算出 Entropy 最常用的幾個數值。

  1. 家教問我心裡想一個 1 到 8 的整數，你只能問「是／不是」的問題，最少要問幾題才保證猜中？

    提示
    最聰明的問法是每題都把剩下的可能砍一半。8 → 4 → 2 → 1，數數看砍了幾刀。
    看答案
    3 題。第一題「大於 4 嗎？」剩 4 個，第二題剩 2 個，第三題剩 1 個。
    這就是 \(\log_2 8 = 3\)，因為 \(2^3 = 8\)。
    所以 \(\log_2 N\) 的白話意思是：N 個一樣可能的答案，要問幾個是非題才猜得到。
    換個角度：一件機率 \(p\) 的事發生了，你的「驚訝度」是 \(-\log_2 p\)。機率 \(\frac18\) 的事，驚訝度就是 3 bit。

  2. 家教問如果只有 3 種一樣可能的答案（剪刀、石頭、布），要問幾題？答案會是整數嗎？

    提示
    \(2^1 = 2 < 3 < 4 = 2^2\)，所以答案夾在 1 和 2 之間。
    看答案
    \(\log_2 3 \approx 1.585\)。不是整數沒關係，它代表「理論上平均最少要問的題數」。
    把每一類的驚訝度 \(-\log_2 p_c\) 乘上它出現的機率 \(p_c\)，再全部加起來（就像高中的期望值），得到的「平均驚訝度」就是 Entropy（熵）：
    \[H = -\sum_c p_c \log_2 p_c\]
    三種各 \(\frac13\)：\(H = -3 \times \frac13 \log_2 \frac13 = \log_2 3 \approx 1.585\)。
    兩種各半（例如 4 個有流感、4 個沒有）：\(H = -2 \times \frac12 \log_2 \frac12 = 1\)，這是兩類時最亂的狀態。

  3. 家教問如果 3 個病人裡 2 個有流感、1 個沒有，亂度會比各半時的 1 大還是小？用公式算算看。

    提示
    比較好猜的那堆，亂度應該比較小。小技巧：\(\log_2 \frac23 = 1 - \log_2 3\)（對數的商等於相減）。
    看答案
    \[H\left(\tfrac13,\tfrac23\right) = -\tfrac13\log_2\tfrac13 - \tfrac23\log_2\tfrac23 = \tfrac13\log_2 3 + \tfrac23(\log_2 3 - 1) = \log_2 3 - \tfrac23 \approx 0.918\]
    比 1 小，因為一律猜「有流感」就有 \(\frac23\) 的機會猜對，沒那麼亂。
    期中考 P1 會一直用到這幾個值，背起來省時間：
    \(H(\frac12,\frac12) = 1\)、\(H(\frac13,\frac23) \approx 0.918\)、\(H(\frac14,\frac34) \approx 0.811\)、\(H(\frac25,\frac35) \approx 0.971\)、\(H(\frac38,\frac58) \approx 0.954\)。

  4. 家教問如果某一群病人裡 2 個有流感、0 個沒有，代進公式會出現 \(0 \cdot \log_2 0\)。可是 \(\log_2 0\) 根本沒定義，該怎麼辦？

    提示
    讓 \(p\) 越來越小試試看：0.1、0.01、0.001，觀察 \(p\log_2 p\) 往哪裡跑。
    看答案
    \(p = 0.1\) 時約 \(-0.332\)，\(p = 0.01\) 時約 \(-0.066\)，\(p = 0.001\) 時約 \(-0.010\)，一路逼近 0。
    所以規定 \(0 \cdot \log_2 0 = 0\)。白話：從來不會發生的事，對平均驚訝度沒有貢獻。
    於是 [2T, 0F]（T 代表有流感、F 代表沒有）這種「純」的一群：\(H = -1 \cdot \log_2 1 - 0 = 0\)，完全確定，一題都不用問。
    決策樹每問一題就把病人分成幾群，每一群叫一個「節點」，它的目標就是一路分到這種熵 = 0 的純節點。

紅筆：失分陷阱

  • 計算機的 log 鍵通常是 log10 或 ln，算熵要用 \(\log_2\)，可以用換底：\(\log_2 x = \frac{\ln x}{\ln 2}\)。
  • 看到某類機率是 0，不要寫「無解」，直接把那一項當 0。
  • 熵最大值 1 只對「兩類」成立；三類各佔 \(\frac13\) 時最大是 \(\log_2 3 \approx 1.585\)。
  • 熵公式前面有負號，算出來一定 ≥ 0，算到負數就是漏了負號。

暖身 2・機率、條件機率與貝氏定理

這題要你學會「先縮小範圍」看條件機率，再用貝氏定理把機率反過來，這就是 Naive Bayes 的全部底子。

  1. 家教問信箱有 100 封信，20 封垃圾信裡有 15 封含「免費」，80 封正常信裡有 8 封含「免費」。\(P(\text{免費}\mid\text{垃圾})\) 是多少？

    提示
    直線「|」右邊代表「先只看這一群」，所以只要看那 20 封垃圾信。
    看答案
    \(P(\text{免費}\mid\text{垃圾}) = \frac{15}{20} = 0.75\)
    同理 \(P(\text{免費}\mid\text{正常}) = \frac{8}{80} = 0.1\)
    條件機率就是篩選器：先把範圍縮小到 | 右邊那群，再數左邊的事佔多少。

  2. 家教問現在反過來：收到一封含「免費」的信，它是垃圾信的機率是多少？會跟 0.75 一樣嗎？

    提示
    先數「含免費」的信總共有幾封，這就是新的範圍。
    看答案
    含「免費」的信共 \(15 + 8 = 23\) 封，其中 15 封是垃圾信：
    \[P(\text{垃圾}\mid\text{免費}) = \frac{15}{23} \approx 0.652\]
    跟 0.75 不一樣！\(P(A\mid B) \neq P(B\mid A)\)。
    寫成公式就是 貝氏定理，其中 \(P(\text{垃圾}) = \frac{20}{100} = 0.2\)、\(P(\text{免費}) = \frac{23}{100} = 0.23\)：
    \[P(\text{垃圾}\mid\text{免費}) = \frac{P(\text{免費}\mid\text{垃圾})\,P(\text{垃圾})}{P(\text{免費})} = \frac{0.75 \times 0.2}{0.23} \approx 0.652\]
    白話：已知「垃圾信長什麼樣子」，反推「長這樣的信是不是垃圾信」。

  3. 家教問如果只想知道「比較像垃圾信還是正常信」，分母 \(P(\text{免費})\) 一定要算嗎？

    提示
    兩類的分母都是同一個 0.23。兩個數除以同一個正數，誰大誰小會改變嗎？
    看答案
    不用算，只比分子就好：
    垃圾：\(0.2 \times 0.75 = 0.15\)；正常：\(0.8 \times 0.1 = 0.08\)。\(0.15 > 0.08\)，判垃圾信。
    這就是公式表那行 \(P(y\mid x) \propto P(y)\prod_i P(x_i\mid y)\)：\(x_i\) 是信裡第 i 個字，「\(\propto\)」是「正比於」（分母直接丟掉），\(\prod\) 是連乘符號，就像 \(\sum\) 是連加。
    信裡有很多字時，就把每個字的機率連乘，並假設字跟字互相獨立。這個大膽的假設就是 Naive（天真） 的由來。
    同一個字出現兩次就乘兩次，期中考 P2 的「$$$ $$$ hello」就是這樣。

  4. 家教問連乘很多個小於 1 的數會發生什麼事？還有，如果某個字在垃圾信裡從沒出現過，機率是 0，整個乘積會怎樣？

    提示
    第一題想想 \(\log(ab) = \log a + \log b\)。第二題：只要乘到一個 0，結果就是……
    看答案
    問題一：數字會小到電腦存不下，所以改取 log，連乘變連加。log 是遞增函數，原本誰大，取完 log 還是誰大。
    問題二：乘到 0 就整個歸零，一個字就判死刑。解法是 Laplace smoothing，每個字的次數都先加 1（就是公式表的 \(\alpha = 1\)）：
    \[P(w\mid y) = \frac{\text{count}(w,y) + 1}{\text{該類總字數} + |V|}\]
    \(\text{count}(w,y)\) 是字 \(w\) 在這類信裡出現幾次，\(|V|\) 是字典裡「不同的字」有幾個。每個字都多算 1 次，總共多出 \(|V|\) 次，所以分母也要加 \(|V|\)，機率加起來才會是 1。
    例如某字在垃圾信出現 0 次、垃圾信共 10 個字、字典有 2 個字：\(\frac{0+1}{10+2} = \frac{1}{12} \approx 0.083\)，不再是 0。

紅筆：失分陷阱

  • \(P(A\mid B)\) 和 \(P(B\mid A)\) 是兩回事，先確認 | 右邊是哪一群。
  • Laplace 的 \(|V|\) 是「這一題字典有幾個字」。期中考公式表寫的 \(|V| = 3\) 是投影片例子，P2 只有 2 個字，要用 \(|V| = 2\)。
  • 分母是「這一類總共出現幾個字」，不是信件封數。
  • 取 log 之後分數都是負的，比大小時「比較不負」的那個贏。

暖身 3・向量內積、直線與點到直線距離

這題要你把 SVM 的 w·x + b 翻譯回高中的直線 ax + by + c = 0，再用點到直線距離算出 margin。

  1. 家教問\(w = (3, 4)\)、\(x = (4, 3)\)，內積 \(w \cdot x\) 是多少？再想想：直線 \(3x_1 + 4x_2 - 12 = 0\) 跟 \(w \cdot x + b = 0\) 有什麼關係？

    提示
    內積就是對應位置相乘再相加。把 \(x = (x_1, x_2)\) 想成點的座標，\(w\) 就是前面那排係數。
    看答案
    \(w \cdot x = 3 \times 4 + 4 \times 3 = 24\)
    直線 \(3x_1 + 4x_2 - 12 = 0\) 其實就是 \(w \cdot x + b = 0\)，其中 \(w = (3, 4)\)、\(b = -12\)。
    也就是說，AI 課本的 \(w\) 就是高中的「法向量」，bias \(b\) 就是高中的常數項 \(c\)。
    期中考 P4 的線 \(x_1 + x_2 = 1.5\)，移項成 \(x_1 + x_2 - 1.5 = 0\)，就是 \(w = (1, 1)\)、\(b = -1.5\)。

  2. 家教問把點 \((4, 3)\) 和 \((0, 0)\) 分別代進 \(3x_1 + 4x_2 - 12\)，各得到什麼？兩點在線的同一側嗎？

    提示
    代進去看正負號就好，正負相反就代表在線的兩邊。
    看答案
    \((4, 3)\)：\(12 + 12 - 12 = 12 > 0\)；\((0, 0)\)：\(-12 < 0\)。一正一負，兩點在線的兩側。
    這就是線性分類器的全部祕密：算 \(w \cdot x + b\)，正的判一類，負的判另一類。
    SVM 會給每個點一個標籤 \(y\)：應該在正的那邊標 \(+1\)，應該在負的那邊標 \(-1\)（期中考 P4 要先自己寫好 class 0 → \(-1\)、class 1 → \(+1\)）。
    標籤乘上代入值，就是 functional margin \(\hat\gamma = y(w \cdot x + b)\)：\((4, 3)\) 標 \(+1\) 得 \(1 \times 12 = 12\)，\((0, 0)\) 標 \(-1\) 得 \((-1)(-12) = 12\)。
    分對的點一定是正數，分錯就會變負數。

  3. 家教問這兩個點離直線各有多遠？請用高中的點到直線距離公式。

    提示
    \(d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}\)，分子剛剛已經算好了。
    看答案
    分母 \(\sqrt{3^2 + 4^2} = 5\)，這就是向量長度 \(\lVert w \rVert\)。
    \((4, 3)\)：\(d = \frac{|12|}{5} = 2.4\)；\((0, 0)\)：\(d = \frac{|-12|}{5} = 2.4\)。
    對照 SVM 名詞：geometric margin = functional margin \(\div \lVert w \rVert\) = 真正的垂直距離，這裡就是 \(\frac{12}{5} = 2.4\)。
    一整份資料的 geometric margin，看的是「離線最近」的那個點，也就是所有距離取最小。
    SVM 想找「最寬的走道」，讓這個最小距離越大越好；貼在走道邊緣、距離剛好最小的那幾個點，就叫 support vector。

  4. 家教問把整條式子乘以 2 變成 \(6x_1 + 8x_2 - 24 = 0\)，這還是同一條線嗎？點 \((4, 3)\) 的代入值和距離各變成多少？

    提示
    線上的點代進兩條式子都會是 0。分子會變，分母 \(\lVert w \rVert\) 也會跟著變。
    看答案
    是同一條線，兩邊同乘 2，解不變。
    代入值：\(24 + 24 - 24 = 24\)，變 2 倍。
    距離：\(\frac{24}{\sqrt{36 + 64}} = \frac{24}{10} = 2.4\)，不變。
    結論（期中考 P4(b) 會考）：\(w, b\) 同乘 \(c > 0\)，functional margin 跟著乘 \(c\)，geometric margin 不變，因為 \(c\) 在分子分母抵消了。

紅筆：失分陷阱

  • 直線要先移項成「… = 0」再讀 \(w\) 和 \(b\)：\(x_1 + x_2 = 1.5\) 的 \(b\) 是 \(-1.5\)，不是 \(1.5\)。
  • 距離公式分子要加絕對值，分母要開根號，最常漏的是根號。
  • 高中 \(ax + by + c\) 裡的 \(b\) 是係數；AI 的 bias \(b\) 對應的是常數 \(c\)，別混在一起。
  • 「縮放不改變 geometric margin」只對 \(c > 0\) 成立，乘負數會讓所有正負號翻面。

暖身 4・指數函數 e^x 與 sigmoid 的形狀

這題要你建立 e^x 的大小感覺，算出 σ(0) = 0.5、σ(2) ≈ 0.88，並理解 sigmoid 為什麼是 S 形、為什麼不用「開關」。

  1. 家教問\(e \approx 2.718\) 是數學裡很常出現的常數，猜猜看 \(e^0\)、\(e^2\)、\(e^{-2}\) 大概是多少？

    提示
    任何數的 0 次方都是 1；負次方就是倒數，\(e^{-2} = \frac{1}{e^2}\)。
    看答案
    \(e^0 = 1\)、\(e^2 \approx 7.389\)、\(e^{-2} = \frac{1}{7.389} \approx 0.135\)
    再誇張一點：\(e^{10} \approx 22026\)，\(e^{-10} \approx 0.0000454\)。
    重點感覺：次方往正跑就爆炸變大，往負跑就趴到幾乎 0，但永遠不會變成負數。

  2. 家教問sigmoid 長這樣：\(\sigma(z) = \frac{1}{1 + e^{-z}}\)。請算 \(\sigma(0)\) 和 \(\sigma(2)\)。

    提示
    \(\sigma(2)\) 的分母是 \(1 + e^{-2}\)，上一步已經算過 \(e^{-2}\) 了。
    看答案
    \(\sigma(0) = \frac{1}{1 + e^0} = \frac{1}{2} = 0.5\)
    \(\sigma(2) = \frac{1}{1 + 0.135} = \frac{1}{1.135} \approx 0.88\)
    順便記：\(\sigma(-2) \approx 0.12\)，剛好是 \(1 - 0.88\)，因為 sigmoid 有對稱性 \(\sigma(-z) = 1 - \sigma(z)\)。
    期中考 P3(c) 前向傳播正好要用 \(\sigma(0)\) 和 \(\sigma(2)\)。

  3. 家教問\(z\) 很大或很負的時候，\(\sigma(z)\) 會往哪裡跑？整條畫出來是什麼形狀？

    提示
    \(z\) 很大時 \(e^{-z}\) 趨近 0；\(z\) 很負時 \(e^{-z}\) 超級大。
    看答案
    \(z \to +\infty\)：\(\sigma \to \frac{1}{1 + 0} = 1\)；\(z \to -\infty\)：分母爆大，\(\sigma \to 0\)。
    所以它是一條從 0 平滑爬到 1 的 S 形曲線，正中間是 \((0, 0.5)\)。
    它像「調光旋鈕」，把任何數字壓進 0 到 1，可以當成機率或神經元的興奮程度。
    注意兩端很平。sigmoid 的斜率剛好是 \(\sigma(z)(1 - \sigma(z))\)：在 \(z = 0\) 是 \(0.5 \times 0.5 = 0.25\)，到 \(z = 5\) 只剩約 0.0066。
    斜率小到學不動叫 vanishing gradient（暖身 5 會看到斜率要一層一層相乘，越乘越接近 0）。
    ReLU \(= \max(0, z)\)（負的變 0、正的照抄）在 \(z > 0\) 時斜率恆為 1，就是來解這個問題的。

  4. 家教問如果把 sigmoid 換成「開關」：\(z > 0\) 輸出 1，否則輸出 0，看起來更簡單。為什麼神經網路不愛用它？

    提示
    想想樓梯：每一階踩的那個平面，斜率是多少？
    看答案
    開關（step function）除了跳躍那一點以外處處是平的，斜率 = 0。
    訓練神經網路要靠斜率（梯度）告訴每個權重「往哪調、調多少」，斜率全是 0 就像車子沒有方向盤。
    期中考 P3(a) 的 Leaky Step 就是這個陷阱：輸出只有 0、0.1、1 三種值，像三階樓梯，在 \(z = -1\) 和 \(z = 1\) 會跳（不連續），其他地方斜率都是 0，梯度下降學不到東西。

紅筆：失分陷阱

  • 分母是 \(1 + e^{-z}\)，負號別漏；漏掉會把 \(\sigma(2)\) 算成約 0.12。
  • \(\sigma(0) = 0.5\)，不是 0。
  • 題目寫輸出層是 linear（no activation）時，就不要再多套一次 sigmoid，這是 P3(c) 的陷阱。
  • Leaky Step 的「Leaky」漏出來的是值 0.1，不是斜率，跟 Leaky ReLU 不一樣，平的地方斜率還是 0。

暖身 5・斜率、導數與連鎖律（一層一層乘）

這題要你用「斜率」理解導數，用「齒輪一層一層乘」理解連鎖律，最後自己拼出 backprop 的公式 (y − t)·a₁。

  1. 家教問直線 \(y = 3x + 1\)，\(x\) 增加 1，\(y\) 增加多少？如果是曲線 \(y = x^2\)，在 \(x = 3\) 這一點的斜率又該怎麼算？

    提示
    曲線的斜率可以拿放大鏡看：讓 \(x\) 只動一點點（例如 0.001），看 \(y\) 動了幾倍。
    看答案
    直線斜率是 3，處處一樣。
    曲線 \(y = x^2\) 在 \(x = 3\)：\(\frac{3.001^2 - 3^2}{0.001} \approx 6.001\)，斜率約 6。
    這個「放大到極小範圍的斜率」就是 導數，記成 \(\frac{dy}{dx}\)（\(y\) 的變化量除以 \(x\) 的變化量）。\(x^2\) 的導數是 \(2x\)，代 3 剛好是 6。
    函數有好幾個變數時，只看其中一個、其他先當常數，叫偏微分，寫成 \(\frac{\partial L}{\partial w}\)。

  2. 家教問\(u = 2x + 1\)、\(y = u^2\)，在 \(x = 1\) 的時候，\(x\) 動一點點，\(y\) 會動幾倍？

    提示
    像齒輪：\(x\) 帶動 \(u\)，\(u\) 再帶動 \(y\)。先算每一層的倍率，再想想該加還是該乘。
    看答案
    第一層：\(\frac{du}{dx} = 2\)（\(x\) 動 1，\(u\) 動 2）。
    第二層：\(\frac{dy}{du} = 2u\)（跟 \(x^2\) 的導數是 \(2x\) 同一個道理），\(x = 1\) 時 \(u = 3\)，倍率是 6。
    兩層齒輪串起來，倍率要相乘：\(\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} = 6 \times 2 = 12\)。
    不放心可以展開驗算：\(y = (2x+1)^2 = 4x^2 + 4x + 1\)，斜率是 \(4 \times 2x + 4 = 8x + 4\)，代 \(x = 1\) 也是 12。
    這就是 連鎖律 chain rule。就像換匯：美元換台幣、台幣再換日圓，總匯率是兩段匯率相乘。

  3. 家教問神經網路猜出 \(y\)、正確答案是 \(t\)，用 loss \(L = \frac12(y - t)^2\) 量猜錯多少，而輸出 \(y = w_1 a_1 + w_2 a_2 + b\)。用連鎖律求 \(\frac{\partial L}{\partial w_1}\)。

    提示
    拆成兩層：\(L\) 對 \(y\) 的斜率，乘上 \(y\) 對 \(w_1\) 的斜率。前面的 \(\frac12\) 會跟平方拿下來的 2 抵消。
    看答案
    第一層：\(\frac{\partial L}{\partial y} = \frac12 \cdot 2(y - t) = y - t\)（把 \(y - t\) 當成上一題的 \(u\)，平方的導數是 2 倍）
    第二層：\(\frac{\partial y}{\partial w_1} = a_1\)（\(w_2 a_2\) 和 \(b\) 跟 \(w_1\) 無關，當常數；\(w_1 a_1\) 就像斜率是 \(a_1\) 的直線）
    相乘：
    \[\frac{\partial L}{\partial w_1} = (y - t) \cdot a_1\]
    這正是期中考 P3(d) Hint 給的公式。Backprop 就是從輸出往回，一層一層把斜率乘回去。

  4. 家教問假設 \(y = 1.5\)、\(t = 1\)、\(a_1 = 0.4\)，梯度是多少？權重 \(w_1\) 應該調大還是調小？

    提示
    梯度指向「上坡」，也就是 loss 變大的方向。我們要下山，找 loss 最低的山谷。
    看答案
    \(\frac{\partial L}{\partial w_1} = (1.5 - 1) \times 0.4 = 0.2\)，是正的。
    正的代表 \(w_1\) 變大 loss 也變大（上坡）。要下山就往反方向走：\(w_1 \leftarrow w_1 - \eta \times 0.2\)（箭頭是「更新成」），也就是把 \(w_1\) 調小。
    \(\eta\) 是每一步的步伐大小，叫 learning rate，例如 0.1。
    直覺檢查：輸出 1.5 比目標 1 大，\(a_1\) 是正的，把 \(w_1\) 調小，輸出就會下降、靠近目標。合理！

紅筆：失分陷阱

  • 是 \((y - t)\) 不是 \((t - y)\)，寫反整個差一個負號。
  • \(\frac12\) 已經跟平方的 2 抵消，不要再多乘 2。
  • 梯度正 → 權重要減少；梯度負 → 權重要增加，梯度下降永遠往梯度的反方向走。
  • 連鎖律是一層一層「乘」，不是「加」。

決策樹：先問最能降低亂度的那一題

你玩過「猜猜我是誰」嗎？厲害的玩家第一題會問「他有戴眼鏡嗎？」這種一問就刷掉一大半人的問題，不會劈頭就問「他叫小明嗎？」。決策樹 Decision Tree 就是讓電腦自己學會「先問哪一題最划算」。怎麼量划不划算？「難猜的程度」叫 Entropy，問完之後難猜的程度降了多少叫 Information Gain。這一章 16 分，先把這把尺練熟，最後再學怎麼幫樹「修剪」，免得它像死背考古題的同學一樣，題目一換就不會。

決策樹 Decision Tree

一連串是非題排成的樹。最上面的根節點 root 問第一題，資料依答案分成兩堆，各自再往下問，問到底的葉節點 leaf 直接給答案，就像「20 個問題」猜謎遊戲。

熵 Entropy

量一堆資料「有多難猜」的分數：\(H = -\sum_i p_i \log_2 p_i\)，\(p_i\) 是每一類佔的比例，\(\log_2 x\) 就是「2 的幾次方會等於 x」。比例都小於 1，log 會是負的，所以前面加個負號把分數翻正。全部同一類是 0（不用猜），兩類各半是 1（只能丟硬幣）。

切一刀之後亂度降了多少：分裂前的 Entropy 減掉分裂後各組 Entropy 的加權平均。IG 越大，代表這個問題越值得先問。

(a) 資訊增益 Information Gain・3 分

原題（英文）
You are given a small dataset of patients, with features: Fever (Yes/No), Cough (Yes/No), and target Flu (True/False). Out of 8 training examples, 4 have Flu = True and 4 have Flu = False. You are building a decision tree to predict Flu.

(a) Information Gain [3 pts] The first split is on Fever. If Fever = Yes: 3 examples (2 True, 1 False); if Fever = No: 5 examples (2 True, 3 False). Calculate the information gain from splitting on Fever. Show your calculation of entropy before and after the split (use log2).

這題要你已知第一刀切在 Fever，算出切之前、切之後的 Entropy，相減得到 Information Gain。

  1. 家教問先暖身：8 個病人裡 4 個有流感、4 個沒有。如果閉著眼睛猜某個人有沒有流感，這堆資料算「很亂」還是「很整齊」？

    提示
    想像丟一枚公正的硬幣猜正反面，你有把握嗎？再把 \(p = \frac{4}{8}\) 代進 \(H = -\sum p\log_2 p\) 算算看。
    看答案
    一半一半最亂，Entropy 剛好是 1：
    \[H(S) = -\frac{4}{8}\log_2\frac{4}{8} - \frac{4}{8}\log_2\frac{4}{8} = -\log_2\frac{1}{2} = 1\]
    因為 \(2^{-1} = \frac{1}{2}\)，所以 \(\log_2\frac{1}{2} = -1\)，前面的負號再把它翻成 \(+1\)。
    記住兩個極端：全部同一類 → 0（完全不用猜）；兩類各半 → 1（只能丟硬幣）。

  2. 家教問用 Fever 切開以後，Fever=Yes 這組有 3 人（2 有流感、1 沒有），Fever=No 這組有 5 人（2 有、3 沒有）。兩組各自的 Entropy 是多少？

    提示
    把 \(p\) 換成 \(\frac{2}{3}, \frac{1}{3}\) 和 \(\frac{2}{5}, \frac{3}{5}\)，代進同一個公式就好。
    看答案
    \[H(\text{Yes}) = -\frac{2}{3}\log_2\frac{2}{3} - \frac{1}{3}\log_2\frac{1}{3}\]
    用 \(\log_2\frac{2}{3} = 1 - \log_2 3\)、\(\log_2\frac{1}{3} = -\log_2 3\) 化簡，得到 \(\log_2 3 - \frac{2}{3} \approx 1.5850 - 0.6667 = 0.9183\)。
    \[H(\text{No}) = -\frac{2}{5}\log_2\frac{2}{5} - \frac{3}{5}\log_2\frac{3}{5} \approx 0.5288 + 0.4422 = 0.9710\]
    兩組都還很接近 1，代表切完之後還是很難猜。

  3. 家教問切完有兩組，那「切完的總亂度」可以直接把 0.9183 和 0.9710 平均嗎？

    提示
    一組 3 個人、一組 5 個人，哪一組對整體的影響比較大？
    看答案
    不能直接平均，要用人數比例做加權平均（3 人那組佔 \(\frac{3}{8}\)、5 人那組佔 \(\frac{5}{8}\)），就像算學期成績時學分多的科目比重大：
    \[H_{\text{after}} = \frac{3}{8}(0.9183) + \frac{5}{8}(0.9710) = 0.3444 + 0.6068 \approx 0.9512\]

  4. 家教問最後一步：Information Gain 就是「亂度降了多少」，算出來是多少？這個數字算大還是小？

    提示
    分裂前減分裂後。這題最大可能值是 1（從最亂一路變成完全整齊）。
    看答案
    \[IG = H(S) - H_{\text{after}} = 1 - 0.9512 \approx 0.0488\]
    題目允許留分數加對數：加權平均化簡後是 \(\frac{5}{8}\log_2 5 - \frac{1}{2}\)，所以精確值是 \(IG = \frac{3}{2} - \frac{5}{8}\log_2 5\)。
    0.0488 很小：光知道有沒有發燒，幾乎猜不出有沒有流感，這題問了跟沒問差不多。
考卷英文作答範本
Entropy before the split (4 True, 4 False):
\(H(S) = -\frac{4}{8}\log_2\frac{4}{8} - \frac{4}{8}\log_2\frac{4}{8} = 1\)

Entropy after the split:
Fever = Yes (2T, 1F): \(H = -\frac{2}{3}\log_2\frac{2}{3} - \frac{1}{3}\log_2\frac{1}{3} = \log_2 3 - \frac{2}{3} \approx 0.9183\)
Fever = No (2T, 3F): \(H = -\frac{2}{5}\log_2\frac{2}{5} - \frac{3}{5}\log_2\frac{3}{5} \approx 0.9710\)

紅筆：失分陷阱

  • 題目要求 show entropy before and after：\(H(S)\)、兩個分支的 Entropy、加權平均三樣都要分開寫，只寫最後的 0.0488 會被扣分。
  • 分裂後的 Entropy 要用人數比例 \(\frac{3}{8}\)、\(\frac{5}{8}\) 加權，直接把兩個數字平均就錯了。
  • 對數一定用 \(\log_2\)；計算機只有 log 或 ln 的話要換底：\(\log_2 x = \frac{\ln x}{\ln 2}\)。
  • (a) 的分佈（Fever 分成 3 人和 5 人）跟 (b) 的表格對不起來，(a) 要當成獨立的假設題，別去翻 (b) 的表格。
  • 中間值多留幾位小數再四捨五入：拿 0.9710 直接乘 \(\frac{5}{8}\) 會得到 0.6069，用更精確的 0.97095 才是 0.6068；最後一位差 1 是捨入誤差，不是算錯。
  • 考場最容易卡在按計算機太慢，先背常用值：\(H(\frac{1}{3},\frac{2}{3}) \approx 0.9183\)、\(H(\frac{1}{4},\frac{3}{4}) \approx 0.8113\)、\(H(\frac{2}{5},\frac{3}{5}) \approx 0.9710\)、\(H(\frac{3}{8},\frac{5}{8}) \approx 0.9544\)。

  1. 家教問題幹說 8 筆裡 4 個 True、4 個 False。先別急著抄，自己數一下表格 Flu 那一欄，真的有 4 個 T 嗎？

    提示

    看答案

    提示

原題（英文）

  1. 家教問訓練集 100 分、新資料考爛，這很像哪一種讀書方式？

    提示

    看答案
    這就是 Overfitting（過擬合）：樹一直切到每片葉子只剩 1、2 筆，連資料裡的雜訊和巧合都背下來。
    就像把考古題答案背得滾瓜爛熟，題目數字一換就不會。

    提示

    看答案
    這叫 Pre-pruning（預剪枝，又叫 early stopping）：
    設上限，例如最大深度 max depth、每片葉子最少樣本數 min samples per leaf，或 IG 小於門檻就不切。
    一停下來，那個節點就變成葉子，答案取多數決。
    樹就不會為了只有一兩筆、很可能是雜訊的資料多切一刀。

  3. 家教問第二個方向：先讓樹長到底，再回頭修剪。要怎麼判斷某個分枝該不該剪？

    提示
    找一份樹在訓練時「沒看過」的資料來當裁判。
    看答案
    這叫 Post-pruning（後剪枝），例如 reduced-error pruning 或 cost-complexity pruning（樹越大扣越多分）：
    先長完整棵樹，再從底部往上，試著把一棵子樹換成一片葉子。
    如果在 validation set（驗證集）上的準確率沒有下降，就剪掉：一樣準就選比較簡單的，那段分枝只是在背訓練資料。
    像園丁修樹：先讓它長，再把亂長的枝剪掉。

  4. 家教問如果你寫「方法一：限制最大深度；方法二：限制每片葉子最少樣本數」，能拿滿分嗎？

    提示
    題目要的是 two distinct strategies，這兩個是不是同一類？
    看答案
    有風險！兩個都屬於 pre-pruning，閱卷者可能只算一個。
    最安全的寫法：一個 pre-pruning、一個 post-pruning，各寫 1–2 句怎麼運作。
    想多寫第三個可以補 Random Forest / bagging：每棵樹用隨機抽出的不同資料訓練，再讓很多棵樹投票，降低 variance（換一批訓練資料，答案就大幅變動的程度）。
考卷英文作答範本
1. Pre-pruning (early stopping): Stop splitting a node when a limit is reached, such as a maximum depth, a minimum number of samples per leaf, or a minimum information gain. The node becomes a leaf labeled with the majority class, so the tree never learns splits supported by only a few noisy examples.
2. Post-pruning (reduced-error / cost-complexity pruning): Grow the full tree first, then work bottom-up and replace a subtree with a leaf whenever accuracy on a held-out validation set does not drop. This removes branches that only memorized the training data.
(Optional) Random Forest / bagging: average many trees trained on bootstrap samples to reduce variance.

紅筆：失分陷阱

  • 兩個方法挑到同一類（例如 max depth 和 min samples 都是 pre-pruning），不算 distinct，可能只拿一半。
  • 只寫名詞不寫怎麼運作；題目要求 explain how each works，每個方法要有 1–2 句說明。
  • Post-pruning 要講清楚是用 validation set 判斷；拿訓練集判斷的話，剪枝只會讓成績變差或不變，看不出有沒有過擬合。

P2

單純貝氏 Naive Bayes：數關鍵字抓垃圾信

15 分建議 25 分鐘

想像你是公司收發室的阿姨，已經看過 100 封垃圾信和 100 封正常信：垃圾信裡「$$$」滿天飛，正常信裡大多是「hello」。今天來了一封新信，你不用讀懂內容，只要「數關鍵字、套經驗」幫它打分數，哪邊分數高就丟進哪個籃子。Naive Bayes 就是把這種直覺寫成機率公式；它「天真（naive）」的地方，是假設每個字各自出現、互不相關。這題 15 分三小題：(a) 從經驗估機率、(b) 幫新信打分數、(c) 說說「天真」的代價。

條件機率 Conditional Probability

\(P(A\mid B)\) 是「已知 B 發生的前提下，A 發生的機率」。這題的 \(P(\text{\$\$\$}\mid\text{Spam})\) 就是「已知是垃圾信，從裡面隨手抽一個字剛好抽到「$$$」的機率」。

高中數學：條件機率

貝氏定理 Bayes' Theorem

把「已知類別看字」翻轉成「已知字猜類別」：\(P(y\mid x)\propto P(y)\,P(x\mid y)\)。\(\propto\) 讀作「正比於」，因為分母 \(P(x)\) 兩類都一樣，比大小時可以不算。

高中數學：貝氏定理

先驗機率 Prior／後驗機率 Posterior

先驗是還沒看信之前的猜測（這題兩類各 0.5）；後驗是看完信裡的字以後，更新過的機率。

高中數學：貝氏定理

條件獨立 Conditional Independence

知道類別之後，每個字出不出現互不影響，所以每個字的機率可以直接相乘，就像獨立事件的 \(P(A\cap B)=P(A)\,P(B)\)。Naive Bayes 的「天真」就是這個假設。

高中數學：獨立事件

拉普拉斯平滑 Laplace smoothing

每個字的次數先加 \(\alpha\)（這題 \(\alpha=1\)），分母加 \(\alpha|V|\)，避免沒見過的字讓機率變成 0。\(|V|\) 是字典裡「不同的字」有幾個。

連乘符號 Product notation

\(\prod_i a_i\) 是把所有 \(a_i\) 全部乘起來，跟 \(\sum_i a_i\)「全部加起來」是一對兄弟。公式表的 Naive Bayes 公式就用到它。

高中數學：數列與級數（Σ 符號）

對數 Logarithm

log 把乘法變加法、次方變係數；而且它是遞增函數，取 log 不會改變誰大誰小。機率都小於 1，所以 log 值是負的。這題用 \(\ln\)，也就是以 \(e\approx 2.718\) 為底的自然對數（計算機上的 ln 鍵）。

高中數學：指數與對數

(a) 參數估計 Parameter Estimation・5 分

原題（英文）
A spam filter uses a Naïve Bayes classifier on email text. Two classes: Spam and Ham. The vocabulary has two words: “$$$” and “hello”. In 100 spam emails: “$$$” appeared 40 times, “hello” appeared 5 times. In 100 ham emails: “$$$” appeared 2 times, “hello” appeared 50 times. P(Spam) = P(Ham) = 0.5. Use Laplace smoothing with α = 1 for word likelihoods.

(a) Parameter Estimation [5 pts] Estimate P(“$$$”|Spam), P(“hello”|Spam), P(“$$$”|Ham), P(“hello”|Ham) using Laplace smoothing. Show the formula for one of them and then give the numeric values.

這題要你用 Laplace smoothing 算出 4 個條件機率：每一類裡，「$$$」和「hello」各佔多少。

  1. 家教問\(P(\text{\$\$\$}\mid\text{Spam})\) 白話是什麼意思？如果把 100 封 spam 裡所有的字都倒進一個袋子，袋子裡總共有幾個字？

    提示
    題目給的是「出現幾次」，不是「幾封信有這個字」。把 spam 那一行的兩個次數加起來看看。
    看答案
    意思是：從 spam 袋子裡隨手抽一個字，抽到「$$$」的機率。
    題目只追蹤字典裡這 2 個字，所以 spam 袋子裡共有 40 + 5 = 45 個字，ham 袋子裡有 2 + 50 = 52 個字。
    分母是這個 45 和 52，不是 100 封信（同一封信裡一個字可能出現好幾次，也可能一次都沒有）。
    如果不做平滑，答案會是 \(\frac{40}{45}\approx 0.889\)。

  2. 家教問假設有個字在 spam 袋子裡一次都沒出現，它的機率會是多少？一封信的分數是很多機率相乘，這會出什麼事？

    提示
    任何數乘上 0 會變成⋯⋯？一個沒見過的字，就能讓整封信的分數歸零。
    看答案
    機率會是 0，整串乘積直接歸零，等於宣判這封信「不可能」是 spam，太武斷了。
    Laplace smoothing 的做法：每個字先送 \(\alpha\) 張保底票（分子 \(+\alpha\)）。字典裡有 \(|V|\) 個字、每個都多拿 \(\alpha\) 張，總票數就多了 \(\alpha|V|\) 張（分母 \(+\alpha|V|\)），這樣機率加起來才會剛好是 1：
    \[ P(w\mid y)=\frac{\text{count}(w,y)+\alpha}{\sum_{w'}\text{count}(w',y)+\alpha\,|V|} \]
    分母的 \(\sum_{w'}\text{count}(w',y)\) 就是步驟 1 算的「該類總字數」；這題 \(\alpha=1\)。

  3. 家教問公式表最後寫著「in the class slides, α = 1 and |V| = 3」。這題的 |V| 要填 3 嗎？

    提示
    |V| 是字典裡「不同的字」有幾個。回去看題目，字典裡有哪些字？
    看答案
    不是 3！ 字典只有 {$$$, hello} 兩個字，所以 \(|V|=2\)。
    公式表那個 3 是上課投影片的例子，照抄就中陷阱了。
    所以分母是 spam：45 + 2 = 47；ham：52 + 2 = 54。
    考卷上寫一句「|V| = 2 since the vocabulary is {$$$, hello}」，讓老師知道你有注意到。

  4. 家教問現在把 4 個機率算出來。算完要怎麼自我檢查？

    提示
    同一類裡，抽到「$$$」和抽到「hello」的機率加起來應該是多少？
    看答案
    \(P(\text{\$\$\$}\mid\text{Spam})=\frac{40+1}{45+2}=\frac{41}{47}\approx 0.872\)
    \(P(\text{hello}\mid\text{Spam})=\frac{5+1}{45+2}=\frac{6}{47}\approx 0.128\)
    \(P(\text{\$\$\$}\mid\text{Ham})=\frac{2+1}{52+2}=\frac{3}{54}=\frac{1}{18}\approx 0.056\)
    \(P(\text{hello}\mid\text{Ham})=\frac{50+1}{52+2}=\frac{51}{54}=\frac{17}{18}\approx 0.944\)
    自我檢查：\(\frac{41}{47}+\frac{6}{47}=1\)、\(\frac{1}{18}+\frac{17}{18}=1\)，每一類加起來都是 1，過關。
考卷英文作答範本

Formula: \(P(w\mid y)=\dfrac{\text{count}(w,y)+1}{\sum_{w'}\text{count}(w',y)+|V|}\)
Total tokens: Spam = 40 + 5 = 45, Ham = 2 + 50 = 52.
\(P(\text{\$\$\$}\mid\text{Spam})=\frac{40+1}{45+2}=\frac{41}{47}\approx 0.872\)
\(P(\text{hello}\mid\text{Spam})=\frac{5+1}{45+2}=\frac{6}{47}\approx 0.128\)
\(P(\text{\$\$\$}\mid\text{Ham})=\frac{2+1}{52+2}=\frac{1}{18}\approx 0.056\)
\(P(\text{hello}\mid\text{Ham})=\frac{50+1}{52+2}=\frac{17}{18}\approx 0.944\)

紅筆：失分陷阱

  • 分母寫成 100（信件數），應該是該類的總字數 45 和 52。
  • 照抄公式表的 |V| = 3，會得到 41/48 這種錯誤分數；這題字典只有 2 個字，|V| = 2。
  • 只在分子 +1、分母忘了 +|V|，結果同一類的機率加起來不等於 1。
  • 只寫數字沒寫公式；題目要求至少寫出一個機率的公式。

(b) Classify a Message [6 pts] A new email contains the words: “$$$ $$$ hello”. Compute the log-probability of Spam and Ham (ignore constant factors equal for both classes). Which class does the classifier predict?

這題要你幫新信「$$$ $$$ hello」分別算出 Spam 和 Ham 的 log 分數，比大小決定它屬於哪一類。

  1. 家教問Naive Bayes 幫一封信打分數的公式長怎樣？「$$$ $$$ hello」裡，「$$$」的機率要用幾次？

    提示
    看公式表：\(P(y\mid x)\propto P(y)\prod_i P(x_i\mid y)\)，\(\prod\) 就是「全部乘起來」。信裡的每一個字都要乘進去，重複的也算。
    看答案
    分數 = 先驗 × 每個字的機率，字出現幾次就乘幾次：
    \[ P(y\mid x)\propto P(y)\cdot P(\text{\$\$\$}\mid y)^2\cdot P(\text{hello}\mid y) \]
    \(\propto\)（正比於）的意思是分母 \(P(x)\) 兩類都一樣，比大小時可以丟掉，這就是題目說的「ignore constant factors」。

  2. 家教問題目要你算 log-probability。為什麼不直接相乘就好？

    提示
    一封信有幾百個字，幾百個小於 1 的數相乘會變多小？log 又能把乘法變成什麼？
    看答案
    小數越乘越小，字一多，電腦就會把它當成 0（underflow，數字小到存不下）。
    log 把「乘」變「加」：\(\log(ab)=\log a+\log b\)，次方變係數：\(\log p^2=2\log p\)。
    log 是遞增函數，原本誰大、取 log 後還是誰大，所以比 log 分數就等於比機率。
    這裡用 \(\ln\)（以 \(e\approx 2.718\) 為底，計算機上的 ln 鍵）；換成 \(\log_{10}\) 或 \(\log_2\) 數字會變、結論不變，考卷上註明底數就好。

  3. 家教問先算 Spam 的分數，三項各是多少？

    提示
    \(\ln 0.5\) 一項、\(\ln\frac{41}{47}\) 要乘 2，最後再加上 \(\ln\frac{6}{47}\)。
    看答案
    \[ \text{Score(Spam)}=\ln 0.5+2\ln\tfrac{41}{47}+\ln\tfrac{6}{47} \]
    \[ \approx -0.693-0.273-2.058\approx -3.025 \]
    小提醒：三個四捨五入後的數字直接相加是 −3.024，用沒四捨五入的值算是 −3.0247，寫 −3.025 或 −3.024 都可以。
    機率都小於 1，所以 log 全是負的，這很正常，不是算錯。

  4. 家教問再算 Ham 的分數，然後跟 −3.025 比一比，哪個比較大？

    提示
    負數比大小就像氣溫：零下 3 度和零下 6.5 度，哪個比較暖？
    看答案
    \[ \text{Score(Ham)}=\ln 0.5+2\ln\tfrac{1}{18}+\ln\tfrac{17}{18}\approx -0.693-5.781-0.057\approx -6.531 \]
    −3.025 > −6.531，Spam 比較「不負」，所以判定 Spam。
    換回機率看：Spam 是 \(0.5\times(\frac{41}{47})^2\times\frac{6}{47}\approx 0.0486\)，Ham 是 \(0.5\times(\frac{1}{18})^2\times\frac{17}{18}\approx 0.00146\)，Spam 大約是 Ham 的 33 倍。
    把兩個加起來當總數，\(P(\text{Spam}\mid x)\approx\frac{0.0486}{0.0486+0.00146}\approx 0.971\)。
    關鍵在「$$$」出現兩次：它在 Ham 裡機率只有 \(\frac{1}{18}\)，被罰兩次就扣到 −5.781。
考卷英文作答範本
Using natural log (base e), \(\text{Score}(y)=\ln P(y)+2\ln P(\text{\$\$\$}\mid y)+\ln P(\text{hello}\mid y)\); the evidence \(P(x)\) is the same for both classes and is ignored.
Spam: \(\ln 0.5+2\ln\frac{41}{47}+\ln\frac{6}{47}\approx -0.693-0.273-2.058\approx -3.025\)
Ham: \(\ln 0.5+2\ln\frac{1}{18}+\ln\frac{17}{18}\approx -0.693-5.781-0.057\approx -6.531\)
Since \(-3.025>-6.531\), the classifier predicts Spam (equivalently \(P(\text{Spam}\mid x)\approx 0.971\), likelihood ratio about 33).

紅筆：失分陷阱

  • 「$$$」出現兩次卻只算一次，忘了乘 2。
  • 負數比大小搞反，以為 −6.531「數字比較大」就選 Ham。
  • 沒註明用哪個 log 底數；用 log2 或 log10 結論一樣，但要寫清楚。
  • 先驗兩邊都是 0.5 可以一起省略，但要寫一句說明，不要讓它默默消失。
  • (a) 如果用錯 |V| = 3，這題結論仍是 Spam，但計算分會被扣。

(c) 獨立假設 Independence Assumption・4 分

原題（英文）
(c) Independence Assumption [4 pts] The words “free” and “$$$” are not independent (they often co-occur in spam). How might this violation of the independence assumption affect the classifier’s performance? (1–2 sentences)

這題要你用 1–2 句話說明：「free」和「$$$」其實常常一起出現，違反獨立假設會讓分類器出什麼問題。

  1. 家教問Naive Bayes 的「Naive（天真）」天真在哪裡？回想 (b)：每個字的機率是怎麼合在一起的？

    提示
    (b) 裡我們把每個字的機率直接相乘。高中學過，什麼情況下 \(P(A\cap B)=P(A)\,P(B)\)？
    看答案
    答案是 A、B 互相獨立的時候。
    所以直接相乘，等於假設知道類別之後，每個字各自出現、互不影響（conditional independence）。
    可是真實世界裡，spam 看到「free」，後面八成跟著「$$$」，它們是結伴出現的。
    所以這個假設在現實中常常不成立。

  2. 家教問如果「free」和「$$$」其實在講同一件事（這封信想騙錢），Naive Bayes 卻把它們當成兩個獨立證據，會發生什麼事？

    提示
    想像法庭上同一個證人換件外套又上台作證一次，法官會不會被說服過頭？
    看答案
    同一個 spam 訊號被重複計算（double-counting）。
    用 (a) 的數字感受一下：一個「$$$」讓 Spam 對 Ham 的比值變成 \(\frac{41/47}{1/18}\approx 15.7\) 倍，先驗各半時 Spam 機率約 94%。
    假設「free」只是「$$$」的影子（總是一起出現、比例一模一樣），它沒帶來新資訊，Naive Bayes 卻再乘一次，變成 \(15.7^2\approx 247\) 倍，Spam 機率被灌到 99.6%。
    結果後驗機率被推向 0 或 1，模型變得過度自信（overconfident），給的機率不準（poorly calibrated）。

  3. 家教問機率不準，是不是就代表分類一定會猜錯？

    提示
    分數變誇張了，但 Spam 和 Ham 誰比較高的「排名」有沒有翻過來？
    看答案
    不一定。很多時候只是分數誇張、排名不變，所以 argmax 決策（挑分數最高的那一類）常常還是對的，這也是 Naive Bayes 在垃圾信過濾很好用的原因。
    風險在於：一封正常信剛好同時有「free」和「$$$」（例如公司活動通知），會被加倍扣分，更容易被誤判成 spam。
    作答時寫出「重複計算 → 過度自信 → 正常信可能被誤判」這條因果鏈，1–2 句就夠。
考卷英文作答範本
Correlated words like "free" and "$$$" are counted as two independent pieces of evidence, so the same spam signal is double-counted; the posterior becomes overconfident (pushed toward 0 or 1) and poorly calibrated. The argmax decision is often still correct, but legitimate emails containing both words are more likely to be misclassified as spam.

紅筆：失分陷阱

  • 只寫「準確率會下降」太空泛，沒講出 double-counting 和 overconfident 這個機制。
  • 斷言「一定會分錯」：其實 argmax 常常還是對的，主要問題是機率不準。
  • 寫成一大段：題目限 1–2 句，抓住因果鏈就好。

換數字練習

換數字練習：字典是 {win, meeting}。訓練資料有 80 封 spam、120 封 ham。80 封 spam 裡「win」出現 30 次、「meeting」出現 8 次；120 封 ham 裡「win」出現 4 次、「meeting」出現 46 次。先驗用信件比例，Laplace smoothing α = 1。
(1) 算出 4 個條件機率。
(2) 寫出兩類的先驗機率。
(3) 用自然對數幫新信「win meeting meeting」打分數，判斷它是 Spam 還是 Ham。

提示
條件機率的分母是「該類總字數 + |V|」，不是信件數；但先驗是用信件數算的（80 和 120）。「meeting」出現兩次，log 要乘 2。
看答案
(1) |V| = 2。Spam 總字數 30 + 8 = 38，分母 38 + 2 = 40；Ham 總字數 4 + 46 = 50，分母 50 + 2 = 52。
\(P(\text{win}\mid\text{Spam})=\frac{31}{40}=0.775\)，\(P(\text{meeting}\mid\text{Spam})=\frac{9}{40}=0.225\)
\(P(\text{win}\mid\text{Ham})=\frac{5}{52}\approx 0.096\)，\(P(\text{meeting}\mid\text{Ham})=\frac{47}{52}\approx 0.904\)
(2) \(P(\text{Spam})=\frac{80}{200}=0.4\)，\(P(\text{Ham})=\frac{120}{200}=0.6\)。

P3

神經網路：樓梯、旋鈕與下山的方向

20 分建議 30 分鐘

想像一間手搖飲料店要研發新口味。店裡有幾位試喝員（隱藏神經元），每個人對甜度、酸度有自己的偏好比重（權重），再加上當天的心情分數（bias），最後用一個「興奮程度轉換器」（激活函數）說出評價。店長再把幾位試喝員的評價加權一次，得出最終分數（輸出）。如果最終分數跟客人真正的喜好差很多，就回頭找出「哪個比重該往哪調、調多少」（反向傳播）。這一大題的 4 小題剛好就是這間店的四個環節：轉換器設計得好不好、店裡有幾個旋鈕、跑一次評分、算出其中一個旋鈕該往哪轉。

神經元 Neuron（權重 Weight 與 Bias）

每個神經元把輸入各乘上自己的權重再加總，最後加一個 bias（像起跳分數），寫成 \( z = w_1x_1 + w_2x_2 + b \)。權重和 bias 就是訓練時可以轉的旋鈕。

高中數學：向量內積

激活函數 Activation function

加權總和之後再過的一個「轉換器」，決定神經元要多興奮。沒有它的話，疊再多層也只是一個大號的線性函數（畫出來還是直的），學不出彎彎曲曲的規律。

高中數學：函數（分段定義的函數）

Sigmoid 函數

\( \sigma(z) = \frac{1}{1+e^{-z}} \)，把任何數壓到 0 到 1 之間，像調光器。\( \sigma(0) = 0.5 \)，z 越大越接近 1，z 越小越接近 0。

高中數學：指數函數

ReLU 與 Softmax

ReLU 是 \( \max(0, z) \)：負的變 0，正的照舊。Softmax 把幾個輸出換成加起來等於 1 的機率。兩個都是固定公式，沒有要學的參數。

高中數學：機率

連續 Continuity

圖形可以一筆畫完、不用提筆。在某一點要「從左邊靠近的值 = 該點的值 = 從右邊靠近的值」才算連續。

高三數甲：函數的極限與連續

梯度 Gradient（斜率）

參數動一點點，損失會跟著變多少，也就是切線斜率。斜率是 0 代表「往哪走都一樣」，模型就不知道該怎麼調。

高三數甲：微分（導數就是切線斜率）

偏導數 Partial derivative

寫成 \( \frac{\partial L}{\partial w} \)，意思是「只轉 w 這一個旋鈕、其他全部固定不動時，L 變化的斜率」。彎彎的 \( \partial \) 讀作 partial，只是在提醒你其他變數先別動。

高三數甲：微分

損失函數 Loss（Squared error）

\( L = \frac{1}{2}(y - t)^2 \) 衡量預測 y 離正確答案 t 有多遠。它是開口向上的拋物線，谷底在 y = t。

高中數學：二次函數

反向傳播 Backpropagation 與連鎖律 Chain rule

從輸出的錯誤往回推，算出每個權重該負多少責任。一層接一層像齒輪連動，每一段的斜率要相乘。

高三數甲：微分

梯度下降 Gradient descent

每次把參數往斜率的反方向走一小步：\( w \leftarrow w - \eta \cdot g \)，其中 \( g \) 是梯度、\( \eta \)（讀作 eta）是步長，也就是每一步跨多大。像蒙眼下山，摸著坡度一步步往低處走。

(a) Leaky Step 激活函數・4 分

原題（英文）
(a) Activation Functions [4 pts] “Leaky Step”: f(z) = 1 if z > 1; 0.1 if −1 ≤ z ≤ 1; 0 if z < −1. Is this function continuous? If not, identify the points of discontinuity. Then discuss one potential issue with using this activation in gradient-based learning.

這題要你判斷 Leaky Step 是不是連續、找出斷點，再說明它為什麼不適合拿來做梯度下降。

  1. 家教問先別急著背定義，我們把它畫出來：z 從很負走到很正，f(z) 依序會是哪幾個值？

    提示
    分三段看：z < -1、-1 ≤ z ≤ 1、z > 1。注意中間那段有等號，代表 z = -1 和 z = 1 本身屬於中間段。
    看答案
    三段分別是 0、0.1、1，畫出來就是一座兩階的樓梯：
    \[ f(z)=\begin{cases}1, & z>1\\ 0.1, & -1\le z\le 1\\ 0, & z<-1\end{cases} \]
    因為等號在中間段，所以 \( f(-1)=0.1 \)、\( f(1)=0.1 \)。

  2. 家教問「連續」可以想成用筆畫圖、中途不能提筆。在 z = -1 和 z = 1 這兩個樓梯邊緣，你的筆需要提起來嗎？

    提示
    每個邊緣檢查三個數是否相等：從左邊靠近的值、那一點本身的值、從右邊靠近的值。
    看答案
    不連續，有兩個斷點：
    在 \( z=-1 \)：從左邊靠近是 0，但 \( f(-1)=0.1 \)，跳了 0.1。
    在 \( z=1 \)：\( f(1)=0.1 \)，但從右邊靠近是 1，跳了 0.9。
    考卷上兩個點都要寫，最好附上左右的值當證據。

  3. 家教問梯度下降像蒙眼下山，只能靠腳底感覺的斜率決定往哪走。這座樓梯在每一段平台上的斜率是多少？

    提示
    在平台上左右挪一點點，高度有變嗎？
    看答案
    平台上高度完全不變，所以斜率 \( f'(z)=0 \)。（\( f'(z) \) 就是 f 在 z 這點的斜率；在 \( z=\pm 1 \) 兩個跳躍點，斜率根本沒有定義。）
    想像權重動一點點，z 跟著動一點點，可是 f(z) 停在平台上一動也不動，輸出和損失也就完全沒變，梯度就是 0。
    反向傳播每經過一層都要乘上 \( f'(z) \)，乘到 0 就全變 0，前面的權重收不到任何「該往哪調」的訊號。
    就像整座山都是平地，蒙眼的人只能站在原地，模型也就學不動。

  4. 家教問它名字叫 Leaky，能不能像 Leaky ReLU 一樣「漏」一點梯度出來救命？

    提示
    Leaky ReLU 是 ReLU 的改良版：z > 0 時輸出 z，z < 0 時輸出 0.01z，所以負半邊還有 0.01 的斜率。那 Leaky Step 的 0.1 是「高度」還是「斜率」？
    看答案
    這是陷阱。Leaky ReLU 漏出來的是斜率，負半邊還有一點坡度，所以學得動。
    Leaky Step 漏出來的 0.1 只是高度，平台還是平的，斜率依然是 0。
    名字有 Leaky，梯度問題卻一點都沒解決。
考卷英文作答範本
No, f is not continuous. It has jump discontinuities at \( z = -1 \) (left limit 0, but \( f(-1) = 0.1 \)) and at \( z = 1 \) (\( f(1) = 0.1 \), but the right limit is 1).
Issue: f is piecewise constant, so \( f'(z) = 0 \) almost everywhere (and undefined at \( z = \pm 1 \)). Backpropagation multiplies by \( f'(z) \), so the gradients flowing back to earlier weights are zero. Gradient descent gets no learning signal, and the weights never update.

紅筆：失分陷阱

  • 只寫一個斷點，或沒寫出左右兩邊的值當證據。
  • 只寫「不可微」就停下來，沒講到重點：其他地方的斜率全是 0，梯度直接歸零。
  • 被名字騙，以為 Leaky 會像 Leaky ReLU 一樣漏出梯度：這裡漏的是高度，不是斜率。
  • 搞錯端點歸屬：等號在中間段，所以 \( f(-1) = f(1) = 0.1 \)。

(b) 數參數量・4 分

原題（英文）
(b) Network Architecture [4 pts] 2 input features, one hidden layer of 3 ReLU units, 2 output units (softmax). How many trainable weights in total? (Include bias weights.) Show how you calculate this.

這題要你算出 2 個輸入、3 個 ReLU 隱藏神經元、2 個輸出的網路，總共有幾個可訓練參數（含 bias）。

  1. 家教問先在紙上畫 2 個圓（輸入）、3 個圓（隱藏層）、2 個圓（輸出）。輸入層到隱藏層之間總共要畫幾條線？

    提示
    每個輸入都要連到每個隱藏神經元，就像 2 個人每人都要跟 3 個人握手。
    看答案
    \( 2 \times 3 = 6 \) 條線。
    每條線就是一個權重 weight，也就是一個訓練時可以轉的旋鈕。

  2. 家教問除了這些線，每個隱藏神經元自己還帶著一個旋鈕，是什麼？題目括號裡特別提醒你了。

    提示
    回想神經元的公式 \( z = w_1x_1 + w_2x_2 + b \)，最後面那個 b。
    看答案

  3. 家教問用同樣的方法算隱藏層到輸出層，再把兩層加起來。

    提示
    3 個隱藏神經元 × 2 個輸出，再加上 2 個輸出神經元各自的 bias。
    看答案
    第二層：\( 3 \times 2 + 2 = 8 \)，總共 \( 9 + 8 = 17 \)。

    \[ (2+1)\times 3 + (3+1)\times 2 = 9 + 8 = 17 \]

  4. 家教問ReLU 和 softmax 要不要也算進參數？

    提示

P4

支撐向量機 SVM：把走道開到最寬

20 分建議 35 分鐘

想像走廊上兩班同學各站一邊，教官要在中間貼兩條膠帶圍出一條走道，規定誰都不能踩進來。走道當然越寬越好，那最寬能開多寬？答案只看最靠近中間的那幾個同學，站在後面的人怎麼動都沒差。SVM 就是在找這條「最寬走道」的正中線，而卡住走道寬度的那幾個同學，就叫 support vector。這章你會發現，算走道寬度用的就是高中學過的點到直線距離公式。

點到直線距離 Point-to-line distance

點 \((x_0, y_0)\) 到直線 \(ax + by + c = 0\) 的距離是 \(\frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}\)。這章的 geometric margin 就是它換了個名字。

高中數學：直線與圓（點到直線距離）

法向量 Normal vector（w）與向量長度 \(\lVert w \rVert\)

直線 \(ax + by + c = 0\) 的係數 (a, b) 是一個垂直於這條線的向量，SVM 裡的 w 就是它。小心字母撞名：SVM 的 b 對應的是常數項 c，不是高中 y 前面的那個 b。\(\lVert w \rVert\) 就是 w 的長度，高中課本寫成 \(|\vec w|\)。

高中數學：平面向量

內積 Dot product / Inner product

\(x \cdot x' = x_1x_1' + x_2x_2'\)，對應座標相乘再相加。課本寫的 \(w^\top x\) 也是內積，就是 \(w_1x_1 + w_2x_2\)，那個 ⊤（轉置）先當成「內積記號」就好。kernel 的整套魔法都建立在內積上。

高中數學：平面向量（內積）

線性可分 Linearly separable

能用一條直線把兩類點完全分在兩側。直線兩側的點代入 \(ax + by + c\)，一邊是正、一邊是負。

高中數學：直線方程式

Functional margin 與 Geometric margin

functional margin \(\hat\gamma_i = y_i(w^\top x_i + b)\) 是「代入直線式再乘上標籤」的原始分數，正數代表分對、負數代表分錯。這裡的 \(y_i\) 是標籤（+1 或 −1），不是縱座標。除以 \(\lVert w \rVert\) 之後才是真正的距離，叫 geometric margin。

高中數學：點到直線距離（分子 vs 整個公式）

支撐向量 Support vector

離分隔線最近的那幾個點，像撐住走道兩邊的柱子。只有它們決定線的位置，其他點移走也沒差。

Soft margin 與 slack 變數

允許少數點壓線或越界，但每越界一點就要罰款。每個點越界多少記作 slack 變數 \(\xi_i\)（ξ 唸作 xi），罰款係數就是 C。

核函數 Kernel 與特徵映射 \(\varphi\)

\(\varphi\)（唸作 phi）是把點搬到高維空間的「搬家函數」。kernel \(K(x, x')\) 是一個捷徑公式，算出來剛好等於兩個點搬家後的內積 \(\varphi(x) \cdot \varphi(x')\)，但不用真的搬過去。

國二：乘法公式（\((a+b)^2\) 展開）

對偶問題 Dual 與權重 \(\alpha_i\)

公式表上 SVM 的另一種寫法。每個點配一個權重 \(\alpha_i\)，像是它的「發言權」，只有 support vector 的 \(\alpha_i\) 不是 0。重點是資料點只以「兩兩內積」的形式出現。

    (2, 2) 搭 −3 是同一條線，只是整條式子乘 2，完全正確，還是課本常用的 canonical form（support vector 的 functional margin 剛好等於 1）。
    (−1, −1) 搭 1.5 雖然也是同一條線，但正負號整個反過來，class 1 代進去變負的。
    我們約定 class 0 → y = −1、class 1 → y = +1，所以要讓 class 1 代入後為正，也就是 w 指向 class 1 那一側。
    這個約定考卷上一定要寫出來，不然 w 的正負號可能被判錯。
考卷英文作答範本
Label class 0 as \(y = -1\) and class 1 as \(y = +1\). Rewrite the line as \(x_1 + x_2 - 1.5 = 0\), so \(w = (1, 1)^\top,\ b = -1.5\). (Any positive multiple, e.g. \(w = (2, 2)^\top, b = -3\), describes the same separator.)

紅筆：失分陷阱

  • 沒寫 class 0 → −1、class 1 → +1 的約定，w 的正負號可能被判錯。
  • 把 w 和 b 的正負號整個弄反，class 1 代入變成負數。
  • 把高中的 b（y 的係數）跟 SVM 的 b（常數項）搞混。
  • 以為答案只有一組，其實任何正數倍都對。

(b) Geometric margin 與 support vectors・3 分

這題要你算出這條線對整份資料的 geometric margin，並列出所有 support vectors。

  1. 家教問高中的點到直線距離公式還記得嗎？點 \((x_0, y_0)\) 到 \(ax + by + c = 0\) 的距離怎麼算？

    提示
    分子是「把點代進直線式再取絕對值」，分母跟法向量的長度有關。
    看答案
    \[ d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}} \]
    高中的分子 \(|ax_0 + by_0 + c|\) 就是 \(|w^\top x_i + b|\)，把絕對值換成乘上 \(y_i\)，就是 functional margin \(\hat\gamma_i\)；分母 \(\sqrt{a^2 + b^2}\) 就是 w 的長度 \(\lVert w \rVert\)。
    所以 geometric margin \(\gamma_i = \hat\gamma_i / \lVert w \rVert\) 就是點到直線距離！
    注意這裡的 \(y_i\) 是標籤（+1 或 −1），不是縱座標。用它取代絕對值，分對的點是正數、分錯的點會變負數，順便幫你檢查有沒有分對。

  2. 家教問用 \(w = (1, 1)^\top, b = -1.5\)，把 6 個點的 functional margin 一個一個算出來。

    提示
    先算 \(x_1 + x_2 - 1.5\)，再乘上那個點的 y，class 0 要乘 −1。
    看答案
    (0,0)：\((-1)(0 - 1.5) = 1.5\)
    (1,0)：\((-1)(1 - 1.5) = 0.5\)；(0,1)：同理 0.5
    (1,1)：\((+1)(2 - 1.5) = 0.5\)
    (2,1)：\((+1)(3 - 1.5) = 1.5\)；(1,2)：同理 1.5
    6 個全是正數，代表每個點都分對了。

  3. 家教問\(\lVert w \rVert\) 是多少？整份資料的 geometric margin 要取哪一個點的？

    提示
    題目說 SVM 要 maximize the smallest geometric margin，看的是「最弱的一環」。
    看答案
    \(\lVert w \rVert = \sqrt{1^2 + 1^2} = \sqrt2\)，最小的 functional margin 是 0.5，所以（分子分母同乘 \(\sqrt2\)）
    \[ \gamma = \frac{0.5}{\sqrt2} = \frac{\sqrt2}{4} \approx 0.354 \]
    就像走道寬度由最靠近走道的人決定，整份資料的 margin 只看最近的點。
    加分小知識：兩個三角形之間最近的距離，是 (1,1) 到邊 (1,0)–(0,1) 的距離 \(1/\sqrt2\)，取一半正好是 \(\sqrt2/4\)，所以這條線剛好就是 hard-margin SVM 的最佳解。

  4. 家教問那 support vectors 是哪幾個點？要列幾個？

    提示
    回頭看第 2 步，哪些點的 functional margin 並列最小？
    看答案
    (1,0)、(0,1)、(1,1) 三個點的 functional margin 都是 0.5，距離都是 0.354，它們就是 support vectors，像撐住走道兩邊的柱子。
    三個都要列，少一個就扣分。
    另外三點的距離是 \(1.5/\sqrt2 \approx 1.061\)，站得比較遠，把它們移走線也不會變。
考卷英文作答範本
With \(w = (1, 1)^\top, b = -1.5\): \(\lVert w \rVert = \sqrt2\). Functional margins \(\hat\gamma_i = y_i(x_1 + x_2 - 1.5)\): (0,0) 1.5, (1,0) 0.5, (0,1) 0.5, (1,1) 0.5, (2,1) 1.5, (1,2) 1.5 (all positive, so every point is correctly classified). Geometric margin \(= \min_i \hat\gamma_i / \lVert w \rVert = 0.5/\sqrt2 = \sqrt2/4 \approx 0.354\). Support vectors: (1,0), (0,1), (1,1).

紅筆：失分陷阱

  • 忘了除以 \(\lVert w \rVert\)，直接把 0.5 當答案。
  • support vectors 只列 1 或 2 個，三個都要寫。
  • class 0 忘了乘 −1，算出負的 margin 還以為分錯了。
  • 把整條走道寬度（0.354 的兩倍，約 0.707）當成主答案；可以寫成註解，主答案是 0.354。

(b) 縮放 w、b・4 分

這題要你說明把 w、b 同乘 c > 0 之後，functional margin 和 geometric margin 各自怎麼變。

  1. 家教問把 w 和 b 都乘 3，變成 \(3x_1 + 3x_2 - 4.5 = 0\)，這條線有移動嗎？

    提示
    方程式兩邊同乘一個不是 0 的數，解會不會變？
    看答案
    沒有移動。\(3x_1 + 3x_2 - 4.5 = 0\) 跟 \(x_1 + x_2 - 1.5 = 0\) 的解完全一樣，是同一條線。
    就像把尺從公分換成公釐，桌子長度沒變，只是讀出來的數字變了。

  2. 家教問那 functional margin 呢？拿 (1,0) 試算看看。

    提示
    \(\hat\gamma = y(w^\top x + b)\)，w 和 b 都乘了 c，括號裡整個會怎樣？
    看答案
    (1,0)：\((-1)(3 \cdot 1 + 3 \cdot 0 - 4.5) = 1.5\)，原本 0.5，變成 3 倍。
    一般來說：
    \[ y_i(c\,w^\top x_i + c\,b) = c \cdot y_i(w^\top x_i + b) = c\,\hat\gamma_i \]
    所以每個 functional margin 都乘上 c。

  3. 家教問geometric margin 呢？分子乘了 c，分母 \(\lVert cw \rVert\) 會怎樣？

    提示
    \(\lVert cw \rVert = \sqrt{(cw_1)^2 + (cw_2)^2}\)，c > 0 時可以把 c 提出來。
    看答案
    \(\lVert cw \rVert = c\lVert w \rVert\)，所以
    \[ \frac{c\,\hat\gamma_i}{c\lVert w \rVert} = \frac{\hat\gamma_i}{\lVert w \rVert} \]
    c 被約掉，geometric margin 不變（c = 3 時還是 \(1.5/(3\sqrt2) = \sqrt2/4\)）。
    很合理：線沒動、點沒動，真正的距離當然不變。這也是 SVM 要比 geometric margin 的原因，functional margin 可以靠放大 w 灌水。

  4. 家教問為什麼題目特別寫 c > 0？如果 c = −1 會怎樣？

    提示
    乘負數後，class 1 的點代進 \(w^\top x + b\) 會變正還是負？
    看答案
    線還是同一條，但正負號全部翻轉，原本分對的點 functional margin 全變成負的，等於把兩類標籤猜反。
    而且 \(\lVert cw \rVert = |c|\,\lVert w \rVert\)，c 為負時約不掉，geometric margin 會跟著變號。
    所以「縮放不影響」只對 c > 0 成立。
考卷英文作答範本
Functional margins: every functional margin is multiplied by c, since \(y_i(c\,w^\top x_i + c\,b) = c\,\hat\gamma_i\). Geometric margin: unchanged, because \(\lVert cw \rVert = c\lVert w \rVert\) and c cancels in \(\hat\gamma_i / \lVert w \rVert\); the boundary is the same line.

紅筆：失分陷阱

  • 以為 geometric margin 也跟著乘 c。
  • 只寫結論沒寫理由，每一句最好帶上「c cancels」或「same line」。
  • 忘了這只在 c > 0 時成立，c 為負數時正負號會翻轉。

(c) 處理不可分資料・4 分

原題（英文）
(c) SVM Margins [4 pts] “Suppose we train a hard-margin SVM… Even if the data is not perfectly separable, the SVM will find a separating line…” Name two ways to handle non-separable data in SVMs. (Hint: one involves a parameter, another involves transforming the data.)

這題要你說出兩種讓 SVM 處理不可分資料的方法：一個靠參數，一個靠轉換資料。

  1. 家教問題幹說 hard-margin SVM 遇到分不開的資料「還是會找到一條線」，你覺得這句話對嗎？

    提示
    hard-margin 規定每個點都要分對、而且站在走道外面，資料分不開時做得到嗎？
    看答案
    不對。hard-margin 的規定是每個點都要滿足 \(y_i(w^\top x_i + b) \ge 1\)，意思是每個點都分對、而且站在走道外面（那個 1 就是 (b) 提過的 canonical form 刻度）。
    資料分不開時，沒有任何線做得到，問題直接無解（infeasible）。而且這份資料其實是可分的。
    考試時不用跟題目吵，答出兩個方法就有分，有空再補一句 hard-margin is infeasible on non-separable data。

  2. 家教問提示說第一個方法「跟一個參數有關」。如果規定太嚴做不到，生活中通常怎麼通融？

    提示
    想像停車場規定「不能壓線」，車位太擠怎樣都停不進去，管理員可以改成什麼規則？
    看答案
    改成「壓線可以，但要罰錢」。這就是 soft-margin SVM：每個點配一個 slack \(\xi_i \ge 0\)，代表它壓線或越界多少，規定放寬成 \(y_i(w^\top x_i + b) \ge 1 - \xi_i\)。目標變成
    \[ \min_{w,b,\xi}\ \frac12\lVert w \rVert^2 + C\sum_i \xi_i \]
    意思是調整 w、b、ξ，讓這個總和越小越好：前半項越小走道越寬（走道半寬是 \(1/\lVert w \rVert\)），後半項是罰款總額，C 就是罰款費率。
    C 很大：幾乎不准犯規，接近 hard margin；C 小：走道開寬一點，容忍少數點犯規。
    這條式子公式表上就有。

  3. 家教問提示說第二個方法「跟轉換資料有關」。如果在平面上怎麼切都切不開，可以怎麼換個角度？

    提示
    想像桌上紅豆圍住綠豆，如果能讓綠豆浮到半空中，從側面看是不是一塊板子就能隔開？
    看答案
    這就是 kernel trick / nonlinear feature mapping：用搬家函數把 x 變成 \(\varphi(x)\)，送到更高維的空間（例如多加 \(x_1^2\)、\(x_1x_2\) 這類新特徵），在那裡變成線性可分。
    常見的 kernel 有 polynomial、RBF。
    下一小題 (d) 就是在考這招的細節。
考卷英文作答範本
1. Soft-margin SVM: introduce slack variables \(\xi_i \ge 0\) and a penalty parameter C, solving \(\min_{w,b,\xi} \frac12\lVert w \rVert^2 + C\sum_i \xi_i\) s.t. \(y_i(w^\top x_i + b) \ge 1 - \xi_i\). C trades off margin width against violations (a large C approaches the hard margin).
2. Kernel trick / nonlinear feature mapping: map \(x \to \varphi(x)\) (e.g., polynomial or RBF kernel) into a higher-dimensional feature space where the data become linearly separable.
(Note: a hard-margin SVM is actually infeasible on non-separable data.)

紅筆：失分陷阱

  • 花時間跟題幹那句錯誤敘述糾纏，答出兩個方法才是拿分重點。
  • 兩個方法寫成同一類，例如 polynomial kernel 和 RBF kernel 都算 kernel 這一招。
  • 把這裡的 C（soft-margin 罰款係數）跟 (d) 的 C（kernel 裡的常數項）當成同一個東西。

(d) 1)2) 展開 polynomial kernel・2 分

原題（英文）
(d) Kernel SVM [5 pts] K(x, x′) = (x1x1′ + x2x2′ + C)². 1) When C = 0, what features are implicitly included? 2) When C = 1, what additional terms appear? 3) Why can kernel SVMs separate data in this richer space without explicitly computing these terms?

這題要你把 \(K(x, x') = (x_1x_1' + x_2x_2' + C)^2\) 展開，說出 C = 0 和 C = 1 各藏了哪些特徵。

  1. 家教問先看 C = 0：\(K = (x_1x_1' + x_2x_2')^2\)。用國中的乘法公式把它展開看看？

    提示
    令 \(a = x_1x_1'\)、\(b = x_2x_2'\)，套 \((a + b)^2 = a^2 + 2ab + b^2\)。
    看答案
    \[ K = (x_1x_1')^2 + 2(x_1x_2)(x_1'x_2') + (x_2x_2')^2 \]
    把只跟 x 有關的放一邊、只跟 x' 有關的放另一邊，它其實是兩個「搬家後向量」的內積 \(\varphi(x) \cdot \varphi(x')\)，其中
    \[ \varphi(x) = (x_1^2,\ \sqrt2\,x_1x_2,\ x_2^2) \]
    所以 C = 0 時只有 degree-2 的項：兩個平方項 \(x_1^2\)、\(x_2^2\)，加上交叉項 \(x_1x_2\)（就是題目說的 \(x_3\)）。

  2. 家教問交叉項前面為什麼是 \(\sqrt2\)，不是 2？

    提示
    內積是「對應項相乘再相加」，那個 2 要平分給 x 和 x' 兩邊。
    看答案
    中間那項是 \(2(x_1x_2)(x_1'x_2')\)，要寫成「x 這邊的某個數」乘「x' 這邊對應的同一個數」。
    只好把 2 拆成 \(\sqrt2 \times \sqrt2\)：\((\sqrt2\,x_1x_2)(\sqrt2\,x_1'x_2')\)。
    考試寫「cross term \(x_1x_2\)」就夠，\(\sqrt2\) 是加分細節。

  3. 家教問換成 C = 1：\(K = (x \cdot x' + 1)^2\)，多出了哪些東西？

    提示
    令 \(a = x \cdot x'\)，\((a + 1)^2 = a^2 + 2a + 1\)，其中 \(a^2\) 就是剛剛 C = 0 的部分。
    看答案
    \[ (x \cdot x')^2 + 2(x \cdot x') + 1 \]
    \(2(x \cdot x') = 2x_1x_1' + 2x_2x_2'\)，對應到 \(\sqrt2\,x_1\)、\(\sqrt2\,x_2\) 兩個一次項（linear terms）；最後的 1 對應常數項 1。
    完整的特徵向量變成 6 維：
    \[ \varphi(x) = (x_1^2,\ \sqrt2\,x_1x_2,\ x_2^2,\ \sqrt2\,x_1,\ \sqrt2\,x_2,\ 1) \]
    如果 C 是一般的正數，展開會多出 \(2C(x \cdot x') + C^2\)，\(\varphi\) 裡對應的是 \(\sqrt{2C}\,x_1\)、\(\sqrt{2C}\,x_2\) 和常數 C。
考卷英文作答範本
1) C = 0: \(K(x, x') = (x \cdot x')^2\), which corresponds to \(\varphi(x) = (x_1^2, \sqrt2\,x_1x_2, x_2^2)\): only degree-2 terms, i.e. the squares \(x_1^2, x_2^2\) and the cross term \(x_1x_2\).
2) C = 1: \(K(x, x') = (x \cdot x')^2 + 2(x \cdot x') + 1\), which adds the linear terms \(\sqrt2\,x_1, \sqrt2\,x_2\) and a constant term 1 to \(\varphi\) (in general, for C > 0: \(\sqrt{2C}\,x_i\) and the constant C).

紅筆：失分陷阱

  • C = 0 只寫平方項，漏了交叉項 \(x_1x_2\)。
  • C = 1 只寫一次項，忘了常數項 1。
  • 把這裡的 C 當成 soft-margin 的罰款係數，兩者完全無關。

(d) 3) 為什麼不用真的算高維特徵・3 分

這題要你解釋 kernel SVM 為什麼能在高維空間分類，卻不用真的算出那些新特徵。

  1. 家教問翻到公式表的 SVM dual，資料點 \(x_i\) 在式子裡是以什麼樣子出現的？

    提示
    它是單獨出現，還是永遠跟另一個點綁在一起？
    看答案
    \[ \max_\alpha \sum_i \alpha_i - \frac12\sum_{i,j}\alpha_i\alpha_j y_i y_j K(x_i, x_j) \]
    \(\alpha_i\) 是每個點的發言權重。資料只以 \(K(x_i, x_j)\) 出現，沒有 kernel 時這個位置放的就是內積 \(x_i \cdot x_j\)。
    預測新點用的決策函數也一樣（算出正的判 class 1、負的判 class 0）：
    \[ f(x) = \sum_i \alpha_i y_i K(x_i, x) + b \]
    資料永遠「兩個點配對」出場，從頭到尾不需要單獨知道 \(\varphi(x)\) 長怎樣。
    第一個得分點：SVM 只用到內積。

  2. 家教問拿 x = (1,1)、x' = (2,1)、C = 1 試算：直接算 \((x \cdot x' + 1)^2\)，跟先展開成 6 維再做內積，答案一樣嗎？

    提示
    捷徑是 \(1 \cdot 2 + 1 \cdot 1 = 3\)，加 1 再平方；展開路線用上一題的 6 維 \(\varphi\)，對應項相乘再相加。
    看答案
    捷徑：\((3 + 1)^2 = 16\)。
    展開：\(\varphi(1,1) = (1, \sqrt2, 1, \sqrt2, \sqrt2, 1)\)、\(\varphi(2,1) = (4, 2\sqrt2, 1, 2\sqrt2, \sqrt2, 1)\)
    內積 \(= 4 + 4 + 1 + 4 + 2 + 1 = 16\)，一模一樣！
    捷徑只要做一次 2 維內積、加 C、平方；展開路線要先蓋出 6 維向量。
    第二個得分點：\(K(x, x') = \varphi(x)^\top\varphi(x')\)，在原空間就能算，\(\varphi\) 永遠不用真的算出來。

  3. 家教問在高維空間切的是一個「平的」邊界，那回到原本的 2 維平面看，邊界會長什麼樣子？

    提示
    高維邊界的方程式裡有 \(x_1^2\)、\(x_1x_2\)、\(x_2^2\) 這些項，畫回 \(x_1\)-\(x_2\) 平面會是什麼曲線？
    看答案
    高維空間的線性邊界，例如 \(w_1x_1^2 + w_2\sqrt2\,x_1x_2 + w_3x_2^2 + \dots + b = 0\)，回到原平面就是圓、橢圓、雙曲線這類二次曲線。
    就像在碗形曲面上用一塊平板切下去，切口投影回桌面是一個圓。
    第三個得分點：feature space 裡的 linear max-margin boundary = input space 裡的 nonlinear boundary。
    （嚴格說，K 要滿足一個叫 PSD／Mercer 的數學條件，才保證背後真的有對應的 \(\varphi\)；考卷上括號註明一句就好。）
考卷英文作答範本
The SVM dual \(\max_\alpha \sum_i \alpha_i - \frac12\sum_{i,j}\alpha_i\alpha_j y_i y_j K(x_i, x_j)\) and the decision function \(f(x) = \sum_i \alpha_i y_i K(x_i, x) + b\) depend on the data only through inner products. Since \(K(x, x') = \varphi(x)^\top\varphi(x')\), each feature-space inner product can be computed cheaply in the original 2-D space (dot product, add C, square), so \(\varphi(x)\) is never formed explicitly. The SVM therefore finds a linear max-margin boundary in the feature space, which is a nonlinear (e.g., quadratic) boundary in the input space (valid for PSD / Mercer kernels).

紅筆：失分陷阱

  • 只寫「kernel 比較快」，沒點出「SVM 只需要內積」這個關鍵。
  • 三個得分點（只用內積、K 取代內積不用算 \(\varphi\)、高維線性 = 原空間曲線）少一個就掉 1 分。
  • 誤以為 kernel 會先把資料真的搬到高維再計算，那就失去捷徑的意義了。

換數字練習

資料：class 0（\(y = -1\)）是 (0,0)、(0,2)、(2,1)；class 1（\(y = +1\)）是 (2,2)、(4,1)、(1,3)。考慮分隔線 \(3x_1 + 4x_2 = 12\)。
(1) 寫成 \(w^\top x + b = 0\)。

分群 Clustering

沒有標準答案（沒有 label）的情況下，把長得像的資料自動分成幾堆。k-means 的 k 就是你事先決定要分幾堆。

質心 Centroid

非凸 Non-convex

Problem 5 k-means 初始化敏感・5 分

原題（英文）
Problem 5. Clustering [5 pts] You run k-means with k = 3 on 2D points. With different initial centroids you might get a different final clustering. Why does k-means have this sensitivity to initialization? Name one method to mitigate it.

這題要你解釋 k-means 為什麼對初始 centroid 很敏感，並說出一個讓結果更穩的方法。

  1. 家教問先暖身：k-means 每一輪其實只做兩件事。假設 3 個集合點（centroid）已經放好了，你猜這兩件事是什麼？

    提示
    第一件事跟「每個點該去哪一組」有關，第二件事跟「集合點要不要搬家」有關。
    看答案
    Assignment step（分組）：每個點去找離自己最近的 centroid，加入那一組。
    Update step（搬家）：每個 centroid 搬到自己組員的平均位置（重心）。
    兩步輪流做，直到沒有人換組就停，叫做收斂（converged）。這套流程叫 Lloyd's algorithm，就是一般說的 k-means。
    k-means 想壓低的分數叫 SSE：每個點到自己組 centroid 的距離平方，全部加起來。
    \[ \text{SSE} = \sum_{j=1}^{k} \sum_{x \in C_j} \lVert x - \mu_j \rVert^2 \]
    \(C_j\) 是第 j 組的點，\(\mu_j\) 是第 j 組的 centroid；在數線上 \(\lVert x - \mu_j \rVert^2\) 就是 \((x - \mu_j)^2\)。
    為什麼 SSE 不會變大？分組時，每個點只會換到更近的 centroid；搬家時，平均數剛好是讓距離平方和最小的位置（把 \(\sum (x-c)^2\) 當成 c 的二次函數配方就看得出來）。
    所以每一步都只會讓 SSE 變小或不變，從來不會變大。記住這句，等一下會用到。

  2. 家教問考題是平面上的點，我們先縮到數線上，比較好算、道理一樣：6 個點 0, 2, 10, 12, 20, 22，k = 3。如果一開始把 centroid 放在 0、10、20，第一輪每個點會分到哪一組？

    提示
    2 離 0 只有 2，離 10 有 8，照「找最近的」分就好。分完再算每組平均，看看第二輪有沒有人換組。
    看答案
    分組：{0, 2}、{10, 12}、{20, 22}。
    centroid 搬到平均：1、11、21。
    再分一次，沒有人換組，收斂。
    SSE = \((0-1)^2+(2-1)^2+(10-11)^2+(12-11)^2+(20-21)^2+(22-21)^2 = 6\)。
    這就是眼睛一看就知道的「三對好朋友」，最理想的分法。

  3. 家教問同一份資料，這次 centroid 一開始放在 0、2、12（一樣是隨機挑 3 個資料點）。跑完的結果會跟剛剛一樣嗎？

    提示
    先分組，算出新的 centroid 之後，特別檢查 10 這個點：它離左邊的 centroid 近，還是離右邊的近？
    看答案
    第一輪：0 歸 0 那組，2 歸 2 那組，10、12、20、22 都離 12 最近。
    更新：centroid 變成 0、2、16（\(\frac{10+12+20+22}{4}=16\)）。
    第二輪：10 到 2 的距離是 8，到 16 是 6，還是留在右邊。沒人換組，收斂。
    SSE = \(0+0+(10-16)^2+(12-16)^2+(20-16)^2+(22-16)^2 = 36+16+16+36 = 104\)。
    同一份資料，一個停在 SSE = 6，一個停在 SSE = 104：左邊 2 個點各霸佔一個 centroid，右邊 4 個點被迫擠成一組。
    這就是題目說的「初始化不同，最後分群就不同」。

  4. 家教問SSE = 104 明明比 6 差很多，為什麼 k-means 不會自己發現、繼續改進？想想第 1 步要你記住的那句話。

    提示
    如果在山裡每一步都只准往下走、不准往上爬，你最後會停在哪裡？
    看答案
    把 SSE 想成山區的高度，k-means 就像一個只會下坡的登山客：每一步都往下，走到「四周都比較高」的山谷就停住，這叫 local minimum。
    在 104 這個狀態，每個點都已經在最近的 centroid 那組，每個 centroid 也都站在組員正中間，兩個步驟都找不到能改的地方。
    你把任何一個 centroid 往旁邊挪一點點，SSE 都會變大；要走到 6 那個更深的山谷，得先爬一段上坡，而 k-means 從來不上坡。
    SSE 的地形不是一個碗（non-convex），而是有很多山谷，起點（初始 centroid）決定你滑進哪一個；最深的那個叫 global minimum，k-means 不保證找得到。
    答題關鍵字：non-convex objective、local minimum、每一步只會讓 SSE 下降。
    只寫「因為隨機」不夠，要寫出「不同起點 → 停在不同的 local minimum」。

  5. 家教問最後一部分：怎麼讓結果比較穩？如果你是那個登山客，怕停在小山谷，你會怎麼做？

    提示
    一個方法是「起點挑聰明一點」，另一個方法是「多爬幾次再比較」。
    看答案
    方法一 k-means++：第 1 個 centroid 隨機挑，之後每個點被選中的機率跟 \(D(x)^2\) 成正比，\(D(x)\) 是它到「最近的已選 centroid」的距離，越遠越容易被選，起點自然分散。
    舉例：第 1 個選到 0，其他點的 \(D(x)^2\) 是 4, 100, 144, 400, 484，總和 1132，2 被選中的機率只有 \(\frac{4}{1132} \approx 0.35\%\)，很難再出現「0 和 2 各霸佔一個 centroid」的爛起點。
    方法二 multiple random restarts：用不同的隨機起點跑很多次，留下 SSE 最小的那一次。
    用剛剛的例子算給你看：隨機挑 3 個資料點當起點，共 \(C^6_3 = 20\) 種組合，其中 4 種會卡在 104（0, 2, 10、0, 2, 12，加上右邊對稱的 10, 20, 22、12, 20, 22），機率 20%；改用 k-means++，卡住的機率降到大約 1%。
    隨機跑 5 次留 SSE 最小的，5 次全卡住的機率只有 \(0.2^5 = \frac{1}{3125} = 0.032\%\)。
    考卷上寫一個方法就有分，兩個都寫更保險。
考卷英文作答範本
k-means (Lloyd's algorithm) minimizes the within-cluster sum of squared distances (SSE), which is a non-convex objective with many local minima. The algorithm alternates two steps: (1) assign each point to its nearest centroid, and (2) move each centroid to the mean of its assigned points. Each step can only decrease (or keep) the SSE, so it is a greedy descent that stops at the first local minimum reachable from the initial centroids. Therefore, different initializations can converge to different local minima, i.e., different final clusterings, and there is no guarantee of reaching the global optimum.
Mitigation: use k-means++ initialization (choose the first centroid at random, then choose each next centroid with probability proportional to \(D(x)^2\), where \(D(x)\) is the distance from x to the nearest centroid already chosen, so the initial centroids are spread out), or run k-means multiple times with different random initializations and keep the run with the lowest SSE.

紅筆：失分陷阱

  • 只寫「因為初始值是隨機的」：沒講到 local minimum 或 non-convex，會被扣分。
  • 說 k-means 不會收斂：錯，它一定會收斂（SSE 只降不升、分組方式有限），只是收斂到 local minimum，不保證是 global minimum。
  • 把 elbow method 當成解法：elbow 是用來挑 k 要設多少，不是解決初始化敏感的問題。
  • 寫了「多跑幾次」卻沒說怎麼挑：要寫 keep the run with the lowest SSE（inertia），不是挑看起來順眼的。
  • 以為 k-means++ 是另一種分群演算法：它只改「怎麼挑起點」，後面一樣是 assignment、update 兩步輪流跑。
  • 把 k-means 跟 k-NN 搞混：k-means 是分群（沒有 label，k 是組數），k-NN 是分類（看最近 k 個鄰居投票），兩個 k 意思不一樣。

    看答案
    2T/2F 一半一半，熵 \(= 1\)，反而比父節點的 \(0.954\) 還高！
    ID3 真正保證的只有 Information Gain 不會是負的：
    \[IG = H(S) - \sum_{v} \frac{|S_v|}{|S|} H(S_v) \ge 0\]
    \(\frac{|S_v|}{|S|}\) 是每一組佔全部的比例，所以後面那一項是子節點的「加權平均熵」。

  2. 家教問(a) 用「20 題猜謎」來想：如果題目都是是非題，而且可以一直問下去，是不是一定猜得到答案？

    提示

    看答案
    一定可以。深度夠的話，每條從根走到葉的路徑就對應表裡的一列（這張表叫真值表），每片葉子寫上那一列的答案就好，所以任何 boolean function 都畫得出來 → (a) 真。
    注意「畫得出來」只是說能力夠強，跟會不會死背是兩回事。

  3. 家教問(c) 把樹上太細的分支剪掉（pruning），會比較不會死背嗎？(d) 同一條路徑上，「Fever = 是嗎？」問兩次有意義嗎？

    提示
    (d) 想想：第一次問完已經知道答案了，第二次問的答案會不會不一樣？
    看答案
    (c) 太細的分支常常只是在背訓練資料裡的雜訊，剪掉後樹變簡單，比較不會 overfitting → 真。
    (d) 離散特徵（只有是／否這種固定選項）在同一路徑上問過一次答案就固定了，再問一定一樣，多餘 → 真。

考卷英文作答範本
Answer: (a), (c), (d). (b) is false: ID3 only guarantees \(IG \ge 0\), i.e., the weighted average entropy of the children never exceeds the parent's; it can stay the same (IG = 0), and a single child can even have higher entropy than the parent (e.g., parent 0.954 vs. child 1.0 in P1(b)). Note for (d): assuming discrete attributes; with continuous thresholds an attribute may be reused.

紅筆：失分陷阱

  • (d) 想太多不敢選：本課 ID3 用的是離散特徵，要選，可以補一句 assuming discrete attributes。
  • 把 (a)「能表示任何函數」跟「會 overfitting」混在一起：能力強是事實，會不會死背是另一回事。

6.2 k-NN・3 分

這題要你判斷 4 句關於 k-NN（找最近的 k 個鄰居來投票）的敘述哪些是真的。

先選出你認為「對」的敘述（可複選），再按對答案。

  • k = 1 時每個訓練點最近的鄰居就是自己（距離 0），一定猜對；只有同一位置有不同標籤的重複點才會錯，題目已排除。

  • k 小時只聽極少數鄰居，換一批資料邊界就大變（variance 高），但能貼合細節（bias 低）。

  • 維度越高，每次算距離要比對的座標越多，KD-tree 這類加速結構也會失效，而且點跟點的距離都差不多，這就是 curse of dimensionality。

  • 多數決投票不限兩類，有幾類都可以直接看哪一類票最多。

  1. 家教問k-NN 就像「問鄰居」：想知道一家餐廳好不好吃，就問住最近的 k 個人，聽多數人的。k = 1 時，拿訓練資料裡的某一個點回頭考模型，離它最近的鄰居是誰？

    提示
    它自己也在訓練資料裡，自己跟自己的距離是多少？
    看答案
    就是它自己！距離是 0，所以它一定照抄自己的標籤、一定答對，訓練誤差 = 0 → (a) 真。
    唯一例外是「同一個位置有兩筆標籤不同的資料」，模型不知道該抄哪一個，但題目已經寫 no duplicate conflicting points，排除了。

  2. 家教問k 很小（只問 1 個鄰居）跟 k 很大（問 50 個鄰居）比，哪一個比較容易被一個怪鄰居帶走？

    提示
    Variance 高 = 換一批資料結果就大變；Bias 高 = 太死板、細節都抓不到。
    看答案
    k 小的時候只聽極少數人，碰到一個怪鄰居就被帶走，換一批資料邊界就大變 → variance 高；但它能貼合每個小細節 → bias 低。
    k 大的時候像問一大群人取多數，邊界平滑又穩定，但細節會被抹掉 → bias 高、variance 低。
    所以 smaller k 會 increase variance、decrease bias → (b) 真。

  3. 家教問(c) 每個點如果有 1000 個特徵（1000 維），找「最近的鄰居」會變容易還是變難？(d) 如果有 3 個類別，投票還能用嗎？

    提示
    1000 維時，每算一次距離要比對 1000 個座標，而且每個點離大家都差不多遠。
    看答案
    維度越高，每次算距離越花時間，KD-tree 這類「先把資料排好、加速找鄰居」的工具也會失效，最後幾乎每個點都要算一遍，搜尋變慢。這叫 curse of dimensionality（維度詛咒）→ (c) 真。
    投票本來就不限兩類，3 類、10 類都是看哪一類票最多 → (d) 真。
    答案 (a)(b)(c)(d) 四個全選。
考卷英文作答範本
Answer: (a), (b), (c), (d) — all true. With k = 1, each training point's nearest neighbor is itself, so training error is 0 (absent conflicting duplicates). Small k gives a jagged decision boundary: high variance, low bias. In high dimensions, distances become less informative and indexing structures (e.g., KD-trees) degrade (curse of dimensionality). Majority voting works for any number of classes.

紅筆：失分陷阱

  • 覺得「四個都對不可能」而故意少選一個，複選題四個全對是常見的。
  • (b) 方向記反：k 小 → variance 高、bias 低；k 大 → 邊界平滑、bias 高。
  • (a) 忽略關鍵：k = 1 時最近的鄰居就是自己。

6.3 Naive Bayes・3 分

這題要你判斷 4 句關於 Naive Bayes（垃圾郵件篩選那一套）的敘述哪些是真的。

先選出你認為「對」的敘述（可複選），再按對答案。

  • NB 把 \(P(x \mid y)\) 拆成各特徵的機率連乘，等於假設「已知類別時，特徵彼此獨立」，這正是 naive 的地方。

  • 零訓練誤差只代表正確類別的機率「最大」（例如 0.7 對 0.3 也算猜對），不代表機率等於 1。

  • 分子加 \(\alpha\)、分母加 \(\alpha |V|\)，沒出現過的值機率也大於 0，連乘不會被一個 0 整個歸零。

  • NB 學的是每一類資料長什麼樣子 \(P(x \mid y)\)、\(P(y)\)，屬於 generative；logistic regression 才是 discriminative。

  1. 家教問Naive 到底天真在哪？公式表寫 \(P(y \mid x) \propto P(y)\prod_i P(x_i \mid y)\)，\(\prod\) 就是把每個字的機率全部乘起來，這樣直接相乘，背後偷偷假設了什麼？

    提示
    高中學過：什麼情況下 \(P(A \cap B) = P(A)P(B)\)？注意每一項後面都有「\(\mid y\)」，也就是「已知類別」。
    看答案
    能直接相乘 = 假設獨立；而且每一項都是「已知類別 \(y\)」底下的機率，所以是「在已知類別的前提下，各特徵互相獨立」，這叫 conditional independence。
    現實中 free 和「$$$」在垃圾信裡常常一起出現（P2(c) 就在講這件事），但 NB 天真地當它們無關，這就是 naive 的地方 → (a) 真。

  2. 家教問如果某個字 \(w\) 在 Spam 的訓練資料裡一次都沒出現，\(P(w \mid \text{Spam})\) 是多少？整串連乘會變成什麼？

    提示
    任何數乘上 0 都是 0。
    看答案
    機率是 0，整串連乘直接歸零，不管其他字多像垃圾信都救不回來。
    Laplace smoothing 就是每個字先送 \(\alpha\) 次假出現：
    \[P(w \mid y) = \frac{\text{count}(w, y) + \alpha}{\sum_{w'} \text{count}(w', y) + \alpha |V|}\]
    \(|V|\) 是字彙表裡有幾個不同的字。分子加 \(\alpha\)、分母加 \(\alpha |V|\)，沒看過的字機率也大於 0 → (c) 真。

  3. 家教問(b) 說：訓練誤差是 0，模型就一定給每個訓練標籤機率 1。如果模型算出某封信 \(P(\text{Spam}) = 0.7\)，而它真的是 Spam，這算答對嗎？

    提示
    分類的時候，只看哪一類的機率比較大。
    看答案
    算答對，因為 0.7 比 0.3 大，模型會判成 Spam。
    訓練誤差 = 0 只代表「正確類別每次都是機率最大的那個」，不代表機率等於 1。
    而且用了 Laplace smoothing，另一類的機率也一定大於 0，正確類別根本到不了 1 → (b) 錯。

  4. 家教問NB 是先學「垃圾信通常長什麼樣子、正常信通常長什麼樣子」，再用 Bayes 定理反推；logistic regression 則是直接學「看到這些字，是垃圾信的機率多少」。哪一種叫 generative（生成式）？

    提示
    generative 的意思是：學會之後，它有辦法照著學到的樣子「生出」一封像垃圾信的信。
    看答案
    NB 學的是 \(P(x \mid y)\)（每一類的信長什麼樣子）和 \(P(y)\)（每一類有多常見），所以是 generative。
    直接學 \(P(y \mid x)\) 的 logistic regression 才是 discriminative（判別式）。
    題目說 NB 是 discriminative → (d) 錯。
    答案 (a)(c)。
考卷英文作答範本
Answer: (a), (c). (b) is false: zero training error only means the correct class always has the highest posterior, not that its probability equals 1. (d) is false: Naive Bayes is a generative model (it models \(P(x \mid y)\) and \(P(y)\)); logistic regression is discriminative.

紅筆：失分陷阱

  • 把「猜對」跟「機率 = 1」畫上等號，誤選 (b)。
  • generative／discriminative 記反：NB = generative，logistic regression = discriminative。
  • (a) 漏看 given the class：不是「特徵完全獨立」，而是「已知類別時」獨立。

6.4 神經網路 Neural networks・3 分

這題要你判斷 4 句關於神經網路訓練的敘述哪些是真的。

先選出你認為「對」的敘述（可複選），再按對答案。

  • ReLU 在正半邊斜率固定為 1，反向傳播時一路乘下去不會縮小，不像 sigmoid 最大斜率只有 0.25。

  • 權重全是 0 時，同一層每個神經元的輸出和梯度都一樣，永遠學一樣的東西（對稱性問題），要隨機初始化。

  • 神經元越多模型能力越強，訓練誤差可以壓更低，但也越容易把雜訊背起來而 overfitting。

  • Backpropagation 就是用 chain rule 把每一層的斜率相乘，把輸出端的誤差一層層往前傳。

  1. 家教問把梯度想成「斜率」。sigmoid（把數字壓到 0 到 1 之間的 S 形曲線）最陡的地方斜率只有 0.25，ReLU 在正半邊是斜率 1 的直線；如果誤差要往回傳過 5 層、每層乘一次斜率，哪一個會先消失？

    提示
    算算 \(0.25^5\) 跟 \(1^5\)。
    看答案
    \[0.25^5 \approx 0.00098, \quad 1^5 = 1\]
    sigmoid 一路乘下去幾乎變 0，前面的層收不到訊號、學不到東西，這叫 vanishing gradient（梯度消失）。
    ReLU 的規則是「負數變 0、正數照抄」，正半邊斜率固定是 1，乘幾層都不會縮小 → (a) 真。
    負半邊斜率是 0，所以題目才特別寫 on positive inputs。

  2. 家教問(b) 如果所有權重一開始都設成 0，同一層的每個神經元算出來的東西會不會一樣？之後更新會變得不一樣嗎？

    提示
    輸入一樣、權重一樣，輸出就一樣；輸出一樣，算出來的梯度也一樣。
    看答案
    每個神經元輸出一樣、梯度一樣，所以每次更新也一模一樣，永遠是一群複製人。整層等於只有一個神經元在做事，這叫對稱性問題（symmetry problem）。
    所以權重要用隨機的小數字開始，讓每個神經元走不同的路 → (b) 錯。

  3. 家教問(c) 隱藏層的神經元越多，模型越能把訓練資料背下來，這是好事還是壞事？(d) 上面「每層斜率相乘、把誤差往回傳」，用的是哪一個數學規則？

    提示
    (c) 想想「只背考古題」的下場；(d) 一層接一層的函數，整體斜率等於每層斜率相乘。
    看答案
    (c) 神經元越多，模型能力越強，訓練誤差可以壓得更低，但也越容易連雜訊一起背起來而 overfitting，前後兩半句都對 → 真。
    (d) 整體斜率 = 每層斜率相乘，這就是 chain rule（連鎖律）；backpropagation 就是用它把輸出端的誤差一層層往前傳 → 真。
    答案 (a)(c)(d)。
考卷英文作答範本
Answer: (a), (c), (d). (b) is false: if all weights start at zero, every neuron in a layer computes the same output and receives the same gradient, so they stay identical forever (the symmetry problem); weights should be randomly initialized.

紅筆：失分陷阱

  • 以為「0 很中立、很安全」而選 (b)。
  • (a) 要知道理由是「ReLU 正半邊斜率 = 1」；負半邊斜率是 0，所以題目特別寫 on positive inputs。
  • (c) 只記得「神經元多 = 比較準」，忘了後半句的 overfitting 風險。

6.5 深度學習正則化 Regularization・3 分

這題要你判斷 4 種防止 overfitting 的方法，哪些描述是正確的。

先選出你認為「對」的敘述（可複選），再按對答案。

  • 盯著驗證集（模型沒看過的模擬考資料）的表現，一開始變差就停止訓練，在還沒死背訓練資料之前收手。

  • 訓練時每次隨機把一部分神經元暫時關掉，逼網路不能只依賴少數幾個神經元；測試時則全部使用。

  • 在損失函數加上 \(\lambda \lVert w \rVert^2\) 這類懲罰，權重被壓小，模型比較簡單平滑。

  • Data augmentation 是把資料翻轉、裁切、加雜訊，變出「更多」訓練資料，不是減少。

  1. 家教問準備考試時一直刷同一本考古題，刷到某個時間點之後，模擬考成績反而開始變差。這時候該怎麼辦？

    提示
    Regularization 這一類方法的共同目標，都是「不要把訓練資料背得太死」。
    看答案
    該停了！Early stopping 就是訓練時另外留一份模型沒看過的資料當「模擬考」（叫驗證集），一看到模擬考分數開始變差就停止訓練，在還沒背死之前收手 → (a) 真。

  2. 家教問(b) Dropout 是訓練時每次隨機讓一些神經元「請假」；(c) Weight decay 是懲罰太大的權重。這兩招為什麼能讓模型比較不會死背？

    提示
    分組報告如果每次都有人隨機請假，其他人還能只靠某一個人嗎？
    看答案
    (b) Dropout：每次隨機關掉一部分神經元，逼大家不能只靠某幾個，每個神經元都得學到有用的東西 → 真（測試時則全部神經元都上場）。
    (c) Weight decay：在損失（衡量模型犯錯多少的分數）裡多加一項 \(\lambda \lVert w \rVert^2\)，也就是所有權重平方加起來再乘上 \(\lambda\)。權重越大罰越重，模型就會變得比較簡單平滑 → 真。

  3. 家教問(d) Data augmentation：把一張貓的照片翻轉、旋轉、調亮度，訓練資料是變多還是變少？

    提示
    一張照片變出好幾張。
    看答案
    變多！augmentation 是「擴增」資料，讓模型看到更多變化，所以比較不會死背。
    題目寫 reduces（減少），方向整個反了 → (d) 錯。
    答案 (a)(b)(c)。
考卷英文作答範本
Answer: (a), (b), (c). (d) is false: data augmentation increases the effective amount of training data by creating transformed copies (flips, crops, noise), which helps reduce overfitting.

紅筆：失分陷阱

  • (d) 跟其他三個一樣是「防 overfitting 的方法」，順手就選了，沒看到 reduces 這個字。
  • Dropout 只在訓練時隨機關閉，測試時所有神經元都會用。
  • Weight decay 是懲罰「大」權重、把權重壓小，不是把權重全部歸零。

6.6 混淆矩陣 Confused?・3 分

這題要你用 TP = 80、FP = 20、FN = 40、TN = 60 算出 Precision、Recall、F1、Accuracy，再比大小。

先選出你認為「對」的敘述（可複選），再按對答案。

  1. 家教問用篩選郵件來想：Precision 是「丟進垃圾桶的信裡，幾成真的是垃圾」，Recall 是「真正的垃圾信裡，我抓到幾成」。照這個意思，兩個的分母各是什麼？

    看答案
    \[\text{Precision} = \frac{80}{80+20} = \frac{4}{5} = 0.80\]
    \[\text{Recall} = \frac{80}{80+40} = \frac{2}{3} \approx 0.667\]
    Precision 比 Recall 大 → (a) 真；兩個不相等 → (c) 錯。

  2. 家教問公式表給的 F1 是 \(F_1 = \frac{2 \times P \times R}{P + R}\)（P、R 就是 Precision、Recall）。把 \(\frac{4}{5}\) 和 \(\frac{2}{3}\) 代進去，F1 會落在兩者之間嗎？

    提示
    用分數算：\(2 \times \frac{4}{5} \times \frac{2}{3} = \frac{16}{15}\)，\(\frac{4}{5} + \frac{2}{3} = \frac{22}{15}\)。
    看答案
    \[F_1 = \frac{16/15}{22/15} = \frac{16}{22} = \frac{8}{11} \approx 0.727\]
    也可以用快算法 \(F_1 = \frac{2TP}{2TP + FP + FN} = \frac{160}{220}\)，答案一樣。
    0.667 < 0.727 < 0.80。F1 是一種「偏向小的那個」的平均，一定夾在 P 和 R 中間，所以 Recall 比 F1 小 → (b) 錯。

  3. 家教問最後算 Accuracy：全部 200 筆裡，猜對的是哪兩格？

    提示
    猜對 = TP + TN，記得 Precision、Recall、F1 都沒用到 TN。
    看答案
    \[\text{Accuracy} = \frac{80+60}{200} = \frac{7}{10} = 0.70 \neq 0.727\]
    → (d) 錯。
    答案只有 (a)。全程用分數算（4/5、2/3、8/11、7/10），比較不會因為四捨五入看錯。
考卷英文作答範本
Answer: (a) only. Precision = 80/(80+20) = 0.80; Recall = 80/(80+40) = 2/3 ≈ 0.667; F1 = 2PR/(P+R) = 2TP/(2TP+FP+FN) = 160/220 = 8/11 ≈ 0.727; Accuracy = (80+60)/200 = 0.70. So precision > recall ((a) true, (c) false); recall < F1 because F1 always lies between precision and recall ((b) false); accuracy 0.70 ≠ F1 0.727 ((d) false).

紅筆：失分陷阱

  • Precision 和 Recall 的分母弄反（FP 和 FN 搞混）。
  • 以為 F1 會比 P、R 都大或都小；其實 F1 一定夾在兩者中間。
  • 四捨五入後 0.70 和 0.727 看起來「差不多」，就誤判相等。
  • 算 Accuracy 忘了加 TN，或分母沒用全部 200 筆。

6.7 學習範式 I：基本觀念・3 分

這題要你分辨 supervised、unsupervised、reinforcement、self-supervised 四種學習方式的描述。

先選出你認為「對」的敘述（可複選），再按對答案。

  • Supervised 就是給模型「輸入＋正確答案」成對的資料去學，例如 P2 的垃圾郵件分類。

  • 沒有標準答案，自己找出群聚或結構，例如 P5 的 k-means。

  • 做決定的程式（agent）跟環境互動，用 reward 的好壞來調整行為，就像訓練寵物用零食當獎勵。

  • Self-supervised 的標籤是從資料本身自動生成的（例如遮掉一個字讓模型猜），不需要外部人工標註。

  1. 家教問用「學煮菜」來比喻：老師給你食譜和成品照片、你自己把一堆食材分類、你煮完讓客人打分數。這三種分別對應哪種學習？

    提示
    有標準答案、沒有答案、只有獎勵分數。
    看答案
    有「輸入＋正確答案」成對的資料 = supervised（像 P2 的垃圾郵件分類）→ (a) 真。
    沒有答案、自己找群聚或結構 = unsupervised（像 P5 的 k-means 分群）→ (b) 真。
    跟環境互動、靠 reward（獎勵分數）的好壞調整做法 = reinforcement learning → (c) 真。

  2. 家教問self-supervised 的「標準答案」是誰給的？想想克漏字：把一句話遮掉一個字，讓模型猜被遮的是什麼。

    提示
    被遮掉的那個字，本來就在原文裡。
    看答案
    答案是從資料自己生出來的，不需要人工標註。遮字猜字、預測下一個字，大型語言模型就是這樣預訓練的。
    題目說 external human-provided labels（外部人工給的標籤）→ (d) 錯。
    答案 (a)(b)(c)。
考卷英文作答範本
Answer: (a), (b), (c). (d) is false: self-supervised learning creates its labels automatically from the data itself (e.g., masking a word and predicting it), without external human annotation.

紅筆：失分陷阱

  • 看到名字裡有 supervised，就以為 self-supervised 也要人工標籤。
  • 把 reinforcement learning 的 reward 跟 supervised 的 label 混為一談：reward 只說好不好，不會告訴你正確答案。

6.8 學習範式 II：進階變形・3 分

這題要你分辨 active、transfer、multi-task、semi-supervised 四種進階學習的描述。

先選出你認為「對」的敘述（可複選），再按對答案。

  • Active learning 還是要標籤，只是挑「最不確定、最有價值」的樣本去請人標，用更少標籤學得更好。

  • 把一個任務或領域學到的知識搬到相關的新任務，例如用一般照片預訓練的模型改去辨識醫學影像。

  • 多個相關任務共用同一套內部特徵（shared representation），像共用同一套基本功，互相提供線索，泛化更好。

  • 少量有標籤資料加上大量沒標籤資料一起訓練，省下標註成本又能提升表現。

  1. 家教問Active learning 的 active 是「主動」做什麼？想像你是學生，主動挑最不懂的題目去問老師。

    提示
    它還是需要老師（人工標註），只是挑著問。
    看答案
    Active learning 會挑「最不確定、最有價值」的樣本去請人標註，用更少的標籤學得一樣好，但不是完全不用標籤。
    題目寫 entirely without labels（完全不用標籤）→ (a) 錯。

  2. 家教問(b)(c)(d) 各配一個比喻：會騎腳踏車再去學騎機車？同時學英文和法文、互相幫忙？老師只改幾題、其他題自己練？

    提示
    分別對應 transfer、multi-task、semi-supervised。
    看答案
    Transfer learning：把一個任務學到的知識搬到相關任務，例如用一般照片預訓練的模型，改去辨識 X 光片 → (b) 真。
    Multi-task learning：多個相關任務共用同一套基本功（前面幾層學到的特徵），互相提供線索，泛化更好 → (c) 真。
    Semi-supervised：少量有標籤＋大量沒標籤的資料一起用 → (d) 真。
    答案 (b)(c)(d)。
考卷英文作答範本
Answer: (b), (c), (d). (a) is false: active learning still uses labels; it selectively queries a human (oracle) for labels on the most informative unlabeled samples, reducing labeling cost rather than eliminating labels.

紅筆：失分陷阱

  • 把 active learning 跟 unsupervised 搞混：active 是「少要一點標籤」，不是「不要標籤」。
  • 看到 entirely、always、never 這種絕對字眼要提高警覺，常常就是錯的那一句。

換數字練習

（新題，跟 6.6 同型）另一個二元分類器的結果是 TP = 60、FP = 40、FN = 20、TN = 80。選出所有正確的敘述：
(a) Precision is higher than recall.
(b) Recall is higher than F1-score.
(c) F1-score lies between precision and recall.
(d) Accuracy is higher than F1-score.

提示
全程用分數算：Precision \(= \frac{TP}{TP+FP}\)、Recall \(= \frac{TP}{TP+FN}\)，F1 用公式表的 \(\frac{2PR}{P+R}\) 或快算法 \(\frac{2TP}{2TP+FP+FN}\)，Accuracy 記得把 TN 加進分子、分母用全部 200 筆。
看答案
\[\text{Precision} = \frac{60}{60+40} = \frac{3}{5} = 0.60\]
\[\text{Recall} = \frac{60}{60+20} = \frac{3}{4} = 0.75\]
\[F_1 = \frac{2 \times 0.6 \times 0.75}{0.6 + 0.75} = \frac{0.9}{1.35} = \frac{2}{3} \approx 0.667\]
（快算法：\(\frac{2 \times 60}{2 \times 60 + 40 + 20} = \frac{120}{180} = \frac{2}{3}\)，一樣。）
\[\text{Accuracy} = \frac{60+80}{200} = \frac{7}{10} = 0.70\]
(a) 0.60 < 0.75，錯。
(b) 0.75 > 0.667，對。
(c) 0.60 < 0.667 < 0.75，對（F1 永遠夾在 P、R 中間）。
(d) 0.70 > 0.667，對。
答案 (b)(c)(d)。這題跟原題剛好反過來：這次 Recall 比較高，但 F1 一樣乖乖夾在中間。

一句話記住先抓偷換的字（always、entirely、reduces、discriminative），F1 永遠夾在 P、R 中間，「標籤從哪來」決定是哪一種學習。

答案經過多位 AI 解題與驗算 agent 交叉比對，數字都用 Python 精確重算；講義內容另經逐章審稿，檢查正確性與高中生可讀性。
