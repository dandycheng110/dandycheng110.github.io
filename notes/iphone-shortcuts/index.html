iOS · Shortcuts · 為你的系統而生

iPhone 捷徑
工具箱

不是通用罐頭捷徑,而是接上你自己的 n8n、Tailscale、Mac mini、Ollama,再加上你每天在用的記帳格式。照著動作流程在「捷徑」App 一步步搭即可——全部都能塞進主畫面或鎖定畫面按鈕。

// 前置設定 · 一次搞定
01

iPhone 安裝 Tailscale 並登入同一個 tailnet——串接 Mac mini／Ollama／n8n 全靠它走內網。

02

iOS「行事曆」已加入含 「00 花費」 的 Google 帳號,且該日曆可寫入(設定 → 行事曆 → 帳號)。

03

要遠端 SSH Mac mini:macOS 系統設定 → 一般 → 共享 → 開「遠端登入」。

04

要手機連 Ollama:啟動時設 OLLAMA_HOST=0.0.0.0 再重啟 ollama,確認 11434 埠開著。

05

「捷徑」App → 設定,確認允許執行(日後要匯入別人的捷徑才需開「允許不受信任的捷徑」)。

// 五個捷徑
01

⚡ 閃電記帳 → 寫進「00 花費」

日常 · 每天用

三秒記一筆,自動套你的格式 🍱 $110 麥當勞,直接落進花費日曆。設成主畫面 widget 或鎖定畫面按鈕最香。

動作流程
  1. 要求輸入(Ask for Input)→ 類型「數字」→ 提示 金額?結果改名成變數「金額」
  2. 從選單中選擇(Choose from Menu)→ 選項如下,每個分支放一個文字動作填入對應 emoji: 🍱 伙食　🚌 客運　🛒 採買　🎓 學校　📚 學習 💊 醫療　🏊 運動　💻 訂閱　💸 雜支　💰 收入
  3. 要求輸入 → 類型「文字」→ 提示 說明?(可留空)改名變數「說明」
  4. 文字(Text)→ 內容打:[類別] $[金額] [說明]中間用半形空格;輸出 = 🍱 $110 麥當勞
  5. 加入新的行事曆活動(Add New Calendar Event)標題＝上一步文字 ／ 全天＝開 ／ 日曆＝00 花費 ／ 開始＝今天
套你的記帳慣例
  • 收入要記負數(你的格式 💰 -$12000 退稅)→ 把「收入」分支的文字改成 💰 - 即可。
  • 投資不計入花費,所以選單不放它;真要記就另開事件標 💼。
  • 「吃存貨($0)」這種:說明照打、金額填 0。
  • 進階玩法:把第 5 步換成 取得 URL 內容 POST 給 n8n,改由 n8n 同步寫 Google Calendar + Notion,手機端零等待。
02

🦞 問家裡的 AI(Ollama over Tailscale)

串接 · 你的私有大腦

手機直接問你 Mac mini 上的 Ollama,完全本地、不經雲端。口袋裡的私有 ChatGPT——還能接上 小光／小暗 的人格。

動作流程
  1. 要求輸入 → 文字 → 想問什麼?
  2. 文字(Text)→ 組 JSON([輸入] 處插入上一步變數,model 換成你 ollama list 的實際名稱): {"model":"llama3.1","prompt":"[輸入]","stream":false}
  3. 取得 URL 內容(Get Contents of URL)URL：http://[mac-mini的tailscale名]:11434/api/generate ／ 方法 POST ／ 標頭 Content-Type: application/json ／ 請求內文＝第 2 步的文字
  4. 取得字典值(Get Dictionary Value)→ 鍵 response
  5. 顯示結果(Show Result)　或　朗讀文字(Speak Text)
注意
  • Mac mini 要先 OLLAMA_HOST=0.0.0.0 並重啟 ollama,手機 Tailscale 要連線中。
  • 嫌慢就維持 stream:false + 用較小模型;回應太長可先在 prompt 限制字數。
03

🔗 一鍵觸發 n8n 工作流

串接 · 接你的自動化

手機按一下就跑你 n8n 的任一 workflow——丟訊息給 Discord 雙機器人、抓 YouTube 選題、跑每日摘要,通通行。

動作流程
  1. (選用)要求輸入 → 文字 → 當作 payload
  2. 取得 URL 內容(Get Contents of URL)URL：https://[你的n8n網域]/webhook/[path] ／ 方法 POST ／ 標頭 Content-Type: application/json {"text":"[輸入]","from":"iphone"}
  3. 顯示結果(Show Result)→ 看 n8n 回傳
n8n 那一端
  • 用 Webhook 節點當 trigger,結尾接 Respond to Webhook 回 200。
  • 走 Tailscale 內網最安全,或用你既有對外網域。
  • 可複製成多顆按鈕,各自指不同 webhook(例:「叫小光發摘要」「跑選題」)。
04

💻 遠端指令 Mac mini(SSH over Tailscale)

串接 · 兩台機都能管

不在電腦前也能對新店／新竹的 Mac mini 下指令——喚醒、重啟服務、跑腳本、看 docker ps。

動作流程
  1. (選用)從選單中選擇:新店機 ／ 新竹機兩分支各帶不同主機名
  2. 透過 SSH 執行 Script(Run Script Over SSH)主機＝該機 Tailscale 名稱或 100.x.y.z ／ 埠 22 ／ 使用者＝你的帳號 ／ 認證＝SSH 金鑰(較佳)或密碼 caffeinate -u -t 1 # 喚醒 docker restart n8n # 重啟服務 ollama ps # 看 Ollama 狀態
  3. 顯示結果(Show Result)
注意
  • macOS 先開「遠端登入」(見前置設定 03)。
  • 建議用 SSH 金鑰:公鑰放 Mac mini 的 ~/.ssh/authorized_keys,私鑰貼進捷徑的金鑰欄,比密碼安全。
05

💊 今日保健食品(A/B 週速查)

日常 · 防鋅超標

解決「這週是 A 還 B?早上吃啥、晚上吃啥」的每日疑惑,守住鋅每日上限 40mg。

動作流程
  1. 從選單中選擇(Choose from Menu)→ A 週 ／ B 週
  2. 每個分支放 顯示提示(Show Alert)或 顯示結果,內容:

    A 週

    早餐 DHC 紅嫩鐵素(鐵)＋ DHC 維他命 B 群 ＋ 基礎(C／D3／Q10…)

    晚餐 Swanson 甘胺酸鋅 30mg (主鋅源)

    B 週

    早餐 DHC 綜合維生素 ＋ 鐵

    晚餐 肝臟萃取+鳥胺酸(鋅6mg)＋ 瑪卡 STRONG(鋅7.5mg)

鐵則 · 別忘了
  • 鐵與鋅間隔 2 小時以上(早餐吃鐵、晚餐吃鋅)。
  • 拔牙／手術前 2 週停:銀杏、EPA 魚油、維生素 E。
  • 抽血健檢前 2–3 天停:生物素 5000mcg(干擾甲狀腺／心肌酵素)。
  • 服用 warfarin 絕對禁:輔酶 Q10。
  • 想全自動判週:開頭用「日期 → 格式化成週數 ww」再判奇偶——但每年週數會位移,手動選最穩。

// 建議搭法

把 01 / 05 放鎖定畫面按鈕(每天會碰),02 / 03 / 04 收進一個「家裡」資料夾或主畫面 widget。串接型的三顆只要 Tailscale 一連,人在哪都能操作你的兩台 Mac mini。
