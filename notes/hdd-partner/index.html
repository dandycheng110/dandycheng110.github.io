收集腳本

腳本在您的機器上執行，全文不到 150 行，歡迎逐行檢查。smartctl -a 只讀取健康數值：不啟動自我檢測、不寫入硬碟，休眠中的碟預設不吵醒。序號用 HMAC-SHA256 雜湊，金鑰只存在您的機器上。

collect_smart.sh唯讀收集腳本（需要 smartmontools 7.0 以上） hdd-replacement-log-template.csv換碟紀錄範本（Excel 可直接開） hdd-partner-onepager.pdf一頁提案（A4 正反兩面） 
# 1. 安裝 smartmontools（Debian／Ubuntu；RHEL 系用 dnf）
sudo apt install smartmontools

# 2. 跑一次（站點代號用 SITE_A 這種代號，不要放公司或主機名稱）
sudo ./collect_smart.sh --site SITE_A --out /var/lib/hdd_smart

# 3. 換碟紀錄上的序號，換成同一套雜湊（要用同一個 --out 資料夾）
./collect_smart.sh --out /var/lib/hdd_smart --hash 原始序號

# 4.（選用）每天早上 9 點自動跑：寫進 /etc/cron.d/hdd_smart
0 9 * * * root /opt/collect_smart.sh --site SITE_A --out /var/lib/hdd_smart

交給我們之前：用文字編輯器打開任一個 .jsonl，搜尋某顆碟的原始序號，確認找不到。只交 .jsonl 和換碟紀錄；不要交 .hmac_key。Synology NAS 沒開 SSH 的話，也可以用 SNMP 讀 SMART，我們可以協助。

常見問題

這算個人資料嗎？
硬碟健康數值描述的是硬碟，不是人。我們不收主機名稱、IP 和原始序號，也優先收機房設備、不收員工個人電腦。這是依個資法第 2 條定義做的判斷；貴單位法務若有疑慮，我們配合調整。
會不會影響硬碟或系統？
不會。smartctl -a 只讀取硬碟自己記錄的健康數值，不啟動自我檢測、不寫入資料，一顆碟不到一秒。
比賽會公開什麼？
只公開彙總結果，例如準確率、故障比例，不公開單顆硬碟，也不公開顆數。依競賽規則，說明書要寫出資料來源，可以寫成「新竹某科技公司（匿名）」；主辦單位可非營利使用作品簡介與影片。這些素材都會先給您審閱。
我們的硬碟不多，也有幫助嗎？
有。幾十顆的一次快照，就能檢查模型在台灣真實環境的表現；壞過的碟尤其珍貴。
模型是用什麼資料訓練的？
用 Backblaze 公開的硬碟統計資料訓練（依其條款標註出處）。貴單位的資料只用於驗證與展示。
