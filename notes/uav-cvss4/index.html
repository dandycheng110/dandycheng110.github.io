在 CVSS 4.0 中，無人機漏洞需區分「受損系統（Vulnerable System，如 Wi-Fi 圖傳晶片、伴隨電腦）」與「後續系統（Subsequent System，如飛控核心 FC、馬達與空域實體安全）」。點擊下方選項即可查看該等級在無人機攻防實驗中的具體判定依據。

🎯 1. 可利用性指標 (Exploitability)

評估攻擊者發動無線電、網路或實體攻擊的門檻

📡 2. 受損系統衝擊 (Vulnerable System)

直接存在漏洞的元件（例：Wi-Fi 模組、SDR 接收機、伴隨電腦）

⚙️ 3. 後續系統與實體安全 (Subsequent & Safety)

受牽連的下游核心（例：飛控 FC 姿態控制、墜機傷人風險）

🧭 無人機資安論文/報告評估架構參考（Trust Boundary 雙系統劃分原則）

步驟一：界定攻擊入口 (AV / AC / AT)

使用 HackRF / Alfa 網卡在射頻範圍內發動攻擊屬於 AV:A (鄰近網路)；若透過 4G/5G 雲端地面站則為 AV:N；需拆機接 UART 為 AV:P。

步驟二：評估受損元件 (VC / VI / VA)

若漏洞在機載 Wi-Fi 路由或 MAVLink 轉發器，評估該通訊模組本身是否被竊聽 (VC)、植入封包 (VI) 或塞爆斷線 (VA)。

步驟三：評估飛控連鎖反應 (SC / SI / SA)

偽造的 MAVLink 封包轉發給飛控 (FC) 後，若能強制 Disarm 停槳或改寫航點，代表後續系統完整性與可用性皆為 High (SI:H / SA:H)。

步驟四：標註物理安全危害 (S / R)

只要攻擊可能造成空中停槳、失控撞擊或墜毀，務必標註 S:P (具實體安全危害) 與 R:I (墜毀無法自動復原)。
